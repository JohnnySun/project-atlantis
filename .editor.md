# Project Atlantis editor guidance

## Commit messages

- All repository-authored commits must follow the Conventional Commits specification.
- Use the form `<type>(<optional scope>): <description>`; omit the scope when it adds no useful context.
- Prefer established types such as `feat`, `fix`, `docs`, `test`, `refactor`, `build`, `ci`, and `chore`.
- Keep the description imperative, concise, and specific. Mark breaking changes with `!` and explain them in a `BREAKING CHANGE:` footer.
- Localization stages should normally use a game-specific scope, for example: `feat(golden-sun-tla): localize drifting peninsula scene`.
