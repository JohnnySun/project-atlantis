# 計畫章程

## 願景

建立一套能由人提供原案、由 AI 協助翻譯和校對、最後由人審核並構建為 GBA 簡體／繁體版本的通用工程。AI 的角色包括候選翻譯、術語一致性檢查、字符覆蓋分析、排版預測和測試輔助；最終譯文與發布決策由人負責。

## 計畫範圍

- 日文、英文或作者原案的結構化導入。
- `zh-Hans`、`zh-Hant` 雙版本翻譯與人工審核。
- 人名、地名、招式、道具、怪物和 UI 術語庫。
- 點陣中文字庫的來源、授權、裁切、補字和遊戲內映射。
- 遊戲專用文字格式、壓縮、指標和渲染器適配。
- 靜態 QA、模擬器測試、實機測試和補丁構建。

## 暫不承諾

- 自動破解任意 GBA 遊戲。
- 未經人工審核就發布 AI 譯文。
- 在倉庫保存或分發商業 ROM、未授權字型或來源不明的完整腳本。
- 保證補丁在所有燒錄卡、模擬器和跨版本存檔上相容。

## 里程碑

### M1：黃金太陽可讀抽取

- 完成自訂中文字碼映射。
- 可將 11,115 條日文／中文文本輸出為結構化記錄。
- 建立首版術語表和問題單。

### M2：簡繁雙軌

- 原案、簡體、繁體及審核狀態可並列維護。
- 建立兩套字形覆蓋報告和遊戲專用最小字庫。
- 能檢測繁簡混用、缺字、術語漂移和超寬行。

### M3：無損回插與測試

- 未修改內容抽出再回插後行為一致。
- 可重現構建 ROM 及 BPS。
- mGBA 與至少一台實機完成核心場景回歸。

### M4：第二款遊戲

- 用另一款 GBA 遊戲驗證核心資料格式和工具介面確實可重用。
- 將遊戲專用邏輯限制在 `games/<game>/`。
