# M1.27：named reader caller、record accessor 與固定 16-bit field

日期：2026-08-16

## 範圍與限制

本回合只沿已命名的 `0x080ac334`／`0x080ac3ac` 16-bit reader，分析一個
bounded direct caller `0x080e1030`、三個 accessor 與兩個 wrapper。沒有使用
GDB/mGBA runtime capture，沒有重做 OBJ/resource 分類，沒有全 ROM glyph/string
掃描，也沒有輸出 record bytes、16-bit unit、decoded text、圖片或翻譯 ledger。

可重現命令：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m127_name_accessor.py \
  --rom /path/to/A5TJ.gba \
  --output /private/tmp/smt2-m127-name-accessor.json
```

工具的 schema 是 `smt2.m1.27.name-accessor.v1`。它只輸出 address、boundary、
literal、stride、field offset、window hash、termination count 與 control contract。

## Confirmed static chain

`0x080e11f8` 與 `0x080e120c` 是 `0x080e1030` 的 direct caller，兩者分別以
EWRAM literal `0x0203b554` 加 `0x58`、`0x0203b5ac` 減 `0x58` 建立 consumer
argument。`0x080e1030` 的 ARM7TDMI Thumb boundary 是
`0x080e1030..0x080e11ee`（446 bytes；instruction-window hash
`657fdd5d60814ff47fafa6a5cf06a3aae70fb59ba95fbfff719e06fe8bd3a592`）。

consumer 的 bounded data-flow：

1. 由 object `+0x40` 讀 primary selector、由 object `+0x42` 讀 secondary
   selector。
2. `r1 <= 0x7f` 呼叫 `0x080bf32c`；`0x80 <= r1 <= 0xcf` 呼叫
   `0x080bf354`；超過 `0xcf` 則把 `r2` 傳給 `0x080bf418`。
3. `0x080bf32c` 與 `0x080bf354` 都以 literal load 指向
   `0x08198b74`，record stride 是 `0x24`，source field 是 record `+0x14`。
   `0x080bf418` 的 literal 是 `0x08198eb4`，stride 是 `0x20`，field 是
   record `+0x0c`。
4. 三個 accessor 都先測 bit `0x8000`；該 bit 置位時只保留 low byte
   `0x00ff`，否則保留輸入的 16-bit index。每個 boundary 都以
   `push {lr}`、`pop {r1}`、`bx r1` 及 literal pool 交叉驗證。
5. 選到的 record field 固定複製 8 個 halfword 到 `sp+0x0c`，在 `sp+0x1c`
   追加 `0x0000`。object flag 分支分別由 `0x080e115a` 呼叫 large reader
   `0x080ac3ac`，或由 `0x080e1178` 呼叫 small reader `0x080ac334`。

這建立了「object field → ROM record + 固定 field → stack staging → named
16-bit reader」的 source/consumer edge；它仍然不是自然 runtime 的 selector
value、scene、category 或 Unicode proof。

## Bounded table metadata

`0x08198b74` 的範圍不是由相鄰資料猜測，而是由 caller 的兩個 threshold 約束：
`0x00..0xcf` 共 208 records、stride `0x24`、window length 7488 bytes。
整個 window hash 是
`77f7e001fcf190fdb7e6ed3018eab438e02d9a47e11630780f8dfb40eae5bdc8`，固定
`+0x14` field 的 aggregate hash 是
`d529dd6265299675cce427bc9b00aeb0cf2094059ae4e6d39119adb6cfdecded`。
在每筆固定 8-unit field 中，163 筆含 `0x0000`，45 筆在固定寬度內沒有
`0x0000`；consumer 仍會在 stack field 結尾追加 zero，因此這是長度/儲存
contract metadata，不是對原文的解碼。

`0x08198eb4` 的 `0x20` path 只做 256-record fixed metadata probe，window hash
是 `4e6fc78e58f6e9b0739284189f4c90982d6c0deee769f989aaa474e8de6522d5`，field
aggregate hash 是 `8085a880aa13816f8e62fdb3151b0e7400b19fd28e5a6c6b00a32007a3f825fe`。
其中 238 筆含 zero、18 筆為 fixed-width；這個 probe 不宣稱 secondary table
extent，也不宣稱 caller 的 `object+0x42` domain。

## Evidence 分層

### Confirmed

- `0x080e1030` 的兩個 object selector load、三個 accessor callsite、threshold
  與 accessor literal/base/stride/field offset。
- shared table 的 caller-bounded `0..0xcf`／208-record addressing contract。
- 8×16-bit copy、stack zero append，以及 small/large named reader 的 BL targets。
- 兩個 wrapper 的 direct caller 與 EWRAM object base literal。

### Provisional

- `m27-shared-record-{ordinal:04d}` 可作為 table-local addressing ID；它不是
  翻譯 ID，也沒有 scene/category 名稱。
- 固定 field 的內容形狀與 `0x0300`/`0x0301` 既有 unit contract 可能屬於同一
  encoded text family，但本回合沒有把它升格為主劇情、惡魔、技能、道具或系統表。
- secondary `0x20` window 可能是相關 record family，但範圍、index domain、
  semantic category 仍未知。

### Negative / unknown

- 本回合沒有 runtime capture，因此沒有自然 selector value、scene frequency、
  source pointer 或 rendered glyph identity。
- Unicode、codepage mapping、字寬、控制碼完整語意與 secondary table extent
  未確認；M2 translation ledger gate 維持 blocked。

## 下一個最小缺口

不要再擴張 graphics/resource 類別。下一步只需選一個可自然到達的 caller
（優先 `0x080e1030` 的 wrapper 或同一 accessor 的一個 direct caller），取得
live object `+0x40/+0x42`、record address、field copy 與 reader argument 的
單次因果證據；若 GDB listener 仍不可用，沿同一 caller 向上最多三層確認 RAM
object/table initializer。只有在 source family 可命名且 code-unit→glyph/Unicode
有獨立交叉證據後，才可解除 ledger gate。
