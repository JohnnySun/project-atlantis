# M1.26：context initializer 與 bounded record-index domain

## Scope

本切片只追 M1.25 已接通的 opcode `0x0A` initializer `0x080DD279`、其
selection-array writer `0x080DDE2C` 與同一 context state machine；沒有掃描其他
command/resource family，沒有 runtime synthetic write，也沒有輸出 source/unit/glyph
或完整原文。可重現入口：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m126_context_index.py \
  --rom /path/to/A5TJ.gba \
  --output /private/tmp/smt2-m126-context-index.json
```

## Confirmed static evidence

- `0x085862A8` bounded stream 的第一筆 command class 是 `0x0A`，其 Thumb pointer
  是 `0x080DD279`；function body `0x080DD278`–`0x080DD2C0` 的 literal/callsite
  與邊界可重現。
- constructor 先把 `r0` 移到 object `+0x24`，再以 `strb` 將 record-index field
  `context+0x02` 設為 `1`，所以相對 queue entry 是 `entry+0x26`。這是 initializer
  default，不是 runtime scene hit 或翻譯 ID。
- constructor 的兩個 named BL 仍分別到 `0x080E3158` 與 `0x080DDE2C`。後者在
  `0x080DDE2C`–`0x080DDEC6` 的 bounded loop 將 object context `+0x15` 起的
  `0x1B` bytes 以 `ordinal+1` class 初始化，domain 是 `1..27`；工具只輸出
  domain/contract/hash，不輸出這些 byte 值。
- M1.25 的 `0x080DD30C`–`0x080DD7C8` state machine 有 5 個 `strb r0,[context+2]`
  writer；它從 context `+0x14` selector 經 `+0x15` array 取得 bounded ordinal，
  再寫回 `entry+0x26`，接到 `0x085861C8 + index*0x08 + 0x04` source pointer
  reader edge。
- 這條 static index domain 可 address M1.24 stable local ID formula 的
  `m18-record-(table_index+1)`；以 `index=1..27` 計，候選 local ID 為
  `m18-record-0002` 到 `m18-record-0028`。這只是 addressing mapping，不是 record
  的日文 identity、scene/category 或 Unicode mapping。

## Gate status

**Confirmed**：initializer default field offset/value class、27-slot ordinal-plus-one
selection array、state-machine writer count、table index/stride/pointer field
contract；沒有把 ordinal 當 code-unit。

**Provisional**：這個 context 是 UI/state selection candidate；M1.24 28-record
family 在此 route 的 bounded index domain 可能跳過 table index 0，但原因與語意未解。

**Unknown / negative boundary**：沒有 fresh mGBA/GDB listener capture，所以沒有自然
transition、live selected index、source RAM provenance、glyph identity 或日文語境。
category、Unicode/codepage、字寬、控制碼完整規則、zh-TW font/reinsert 仍未知；
M2 ledger gate 維持 blocked。既有 listener/socket blocker 與這份 static evidence
分層，沒有 synthetic selector/table/state write。

## Next minimal gap

在不重做 graphics/resource 分類的前提下，沿這個唯一 bounded context 再找一個
可命名的 state selector caller 或 RAM object initializer，或在 runtime listener
恢復時取得自然 `entry+0x26`→source pointer→reader/glyph edge。若仍沒有 natural hit，
只記錄 category boundary，不把 `m18-record-0002..0028` 直接升格為可翻譯 source。
