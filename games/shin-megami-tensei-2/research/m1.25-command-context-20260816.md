# M1.25：`0x13` command context 到 28-record source-table reader

## Scope

本切片只沿一條已命名的 data/command/function path，沒有再做全 ROM glyph
pattern、command 或 string scan，也沒有 runtime synthetic table/state write。可重現
入口：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m125_command_context.py \
  --rom /path/to/A5TJ.gba \
  --output /private/tmp/smt2-m125-context.json
```

工具只輸出 address、function boundary、window hash、length、count、opcode class
與 field contract；不輸出 raw descriptor/command/source/unit/glyph bytes、解碼文字、
圖片或 translation ledger。

## Confirmed static chain

```text
descriptor 0x085819A0 + 0x0C
  -> 0x085862A8 named command stream
  -> offset 0x148: opcode 0x13, Thumb pointer 0x080DD7CD
  -> callback table[0x13] at 0x0815EF84
  -> first callback 0x080AD540 stages pointer at queue entry +0x20
  -> queue drain 0x080AD0BE / 0x0815CCC4 calls staged pointer with r0=queue entry
  -> 0x080DD7CC renderer/context function
  -> signed byte at queue entry +0x26 selects table record
  -> 0x085861C8 + index * 0x08 + 0x04 source pointer
  -> 0x080DD884 -> 0x080AC3AC 16-bit reader
```

具體 bounded 結果：

- `0x085819AC` 的 dword 是 named stream pointer `0x085862A8`；只保留 descriptor
  `0x085819A0` 起 `0x20` bytes 的 hash，其他欄位不命名語意。
- 在 stream 起點起 `0x200` bytes 的 bounded window 內，`0x080DD7CD` 只出現一筆，
  前一個 command class 是 `0x13`，record length 是 opcode 加 Thumb pointer 的
  2 words；pointer 後立即接下一個 command class `0x0C`。
- callback table `0x0815EEEC` 的 entry 19（stride `0x08`）與 `0x080AD541`／
  `0x080AD555` 完全相符。第一 callback body `0x080AD540`–`0x080AD550` 以
  `BX LR` 結束：從 `0x03003B84` 的 cursor chain 取 command pointer，寫入 queue
  entry `+0x20`，並遞增 entry `+0x10`。第二 callback `0x080AD554`–`0x080AD558`
  是 `BX LR` leaf。
- queue drain 的 staged-function callsite 是 `0x080AD0BE`，其 target 是
  `0x0815CCC4`（`BX r1`）；該 callsite 前的 contract 是 `r1=entry+0x20`、
  `r0=entry`。因此這一筆 command 確實把 `0x080DD7CD` 接到 context function，
  不是把 function pointer 當成文字 code-unit。
- `0x080DD7CC` 的 bounded function boundary 是 `0x080DD7CC`–`0x080DDACC`；
  `0x080DD862` literal load 指向 `0x085861C8`。其 source load contract 是：
  signed byte `entry+0x26`、乘 `0x08`、加 table `+0x04`，再於 `0x080DD884`
  呼叫 `0x080AC3AC`。reader boundary 與 target 均交叉通過。
- 同一 UI/state machine `0x080DD30C`–`0x080DD7C8` 內可數到 5 個對 object
  `+0x24+0x02` 的 bounded record-index byte writes；這證明 index 有 state writer，
  但沒有自然 runtime value，不能把任一筆 table record 命名成特定場景。

## Evidence gate

**Confirmed**

- descriptor field → command stream → opcode 19 callback → staged Thumb function
  → 28-record table pointer field → 16-bit reader 的 static provenance。
- queue entry 的 opcode/index/staged-function 欄位 contract；`0x13` command 的
  length 與 callback first/second 分工。
- `0x085861C8` 的 stable local ID/addressing 可由 M1.24 重抽取，且 reader 仍是
  16-bit unit、`+2` advance、`0x0300` line break／`0x0301` terminator family。

**Provisional**

- 這條 command target 是 UI/state context candidate；28 records 是一個 category
  candidate，不是主劇情總表，也不是已命名的惡魔、技能或道具表。
- `entry+0x26` 是自然 selection/index 的候選欄位；目前只有 static writer，沒有
  fresh mGBA/GDB natural hit。

**Unknown / negative boundary**

- 本切片沒有 runtime capture，因此不知道自然畫面、按鍵 transition、實際 selected
  record index，也沒有 source pointer 的 live RAM provenance。
- Unicode/codepage、日文 glyph identity、字寬、完整 control-code contract、
  zh-TW font replacement 與可逆回插仍未知。不能以 command pointer、font-bank
  shape 或人工 OCR 建立翻譯 ledger。
- 既有 GDB listener/socket blocker 仍與這份 static evidence 分層；本工具沒有宣稱
  runtime natural scene，也沒有寫入 selector/table/state。
