# M1.36：named source/index caller provenance（2026-08-17）

本回合停止沿 M1.15/M1.16 resource／OBJ class 深挖，只追三條已由 M1.27、M1.30、
M1.31 命名的資料 consumer。工具
`tools/m136_source_index_provenance.py` 僅輸出函式 boundary、PC/callsite、
literal address、RAM table shape、field offset、長度與 hash；不輸出 source bytes、
16-bit unit、日文、glyph、圖片或 translation ledger，也不寫入 RAM table。

本回合已修正，原始 report 仍只存在 `/private/tmp`。

## Confirmed static edges

| family | bounded RAM/index source | accessor/table edge | upward BL evidence |
| --- | --- | --- | --- |
| item | `0x0203a454 + 0x9c + loop_index*2`，16-bit，`0xffff` stop，valid shared index `<=0xcf` | `0x080bf32c` → `0x08198b74 + index*0x24`，field `+0x14` | accessor → `0x080d2b70` → `0x080d2d80` → `0x080d3264`，2 layers |
| skill | `0x0203b860 + 0x5d` bounded byte list，7 slots，valid byte `<=0x3f` | `0x080bf5c0` → `0x0819b9f4 + index*0x1c`，field `+0x06` | accessor → `0x080cd1f8` → `0x080cb928` → `0x080c9bcc`，2 layers |
| demon | object `+0x26`，5 個 16-bit slots，object 來自 EWRAM `0x0203b554+0x58` 或 `0x0203b5ac-0x58` | `0x080bf648` → `0x0819cb74 + index*0x60`，field `+0x22` | accessor → `0x080e1644` → 兩個 EWRAM wrapper，2 layers |

三條 path 的所有 9 個 named callsite／upward edge 都 match 預期 Thumb BL target。
函式 window hash 與預期 boundary 也由 probe 保留；其中 skill leaf、demon tiny
wrapper 使用 end-slot `BX` 作為 boundary cross-check，避免把 literal pool 後方的
下一個函式誤合併。

## Evidence 分層

### Confirmed

- item path 的 index 並非抽象猜測：命名函式從 live EWRAM base literal 加上固定
  `0x9c` 與 halfword loop index 讀取，遇到 `0xffff` 停止，並依 `<=0xcf` 分流到
  shared accessor。這把 `0x08198b74` 的 caller-bounded 208-record addressing
  接到實際 RAM index producer。
- skill path 的命名 state handler 從 bounded EWRAM byte list 取最多 7 個 index，
  只把 `<=0x3f` 的值送進 `0x080cd1f8`，再由 `0x080bf5c0` 讀
  `0x0819b9f4` 的 `+0x06` field。這是 byte index→record field 的 static edge，
  不是把 record ordinal 猜成 Unicode。
- demon path 的 object consumer 讀 `object+0x26+slot*2` 的 5 個 halfword，經
  `0x080bf648` 讀 `0x0819cb74` 的 `+0x22` field；兩個 wrapper 的 EWRAM object
  base／正負 `0x58` offset 也有 literal match。
- 三條 path 的 table-local addressing、field width 與 M1.28/M1.30/M1.31 的
  bounded identity namespace 維持分離；沒有將 item、skill、demon 合成一張表。

### Provisional

- 三個 RAM source 都是自然選擇資料的候選 producer，因為它們在命名 consumer
  之前提供 index；但本回合未有 mGBA live watch／scene transition，不能替它們命名
  具體畫面或自然觸發頻率。
- item 的 `0x00..0xcf` 是 caller threshold domain；skill/demon 的 table extent
  仍只由既有 bounded identity cohort 加上本回合 addressing edge 支持，不能從
  連續位址推導完整 family。

### Unknown / blocked

- 本機 GDB listener 既有 socket blocker 尚未解除，因此沒有 live selector／record
  index／source pointer 值，也沒有把 static edge 寫成 runtime natural hit。
- 未 anchor 的 code-unit→Unicode/codepage、完整 item/demon/skill extent、main/event/
  system source table、自然 scene category、完整字寬與回插 contract 仍未知。
- translation ledger、encoder、font replacement、BPS、round-trip 與 runtime QA 仍
  封鎖；本回合不建立 source table 或翻譯資料。

## 下一個最小缺口

以三條已確認的 static producer 為入口，分別完成 item `0x08198b74` 的 category
spans、skill `0x0819b9f4`／demon `0x0819cb74` 的 bounded table extent；每個新增
record 仍須以 source hash、termination、可重抽取 stable ID 與多來源 identity 或
明確 negative 支持。若自然 runtime listener 仍不可用，不重複 reset→Start，也不做
graphics/resource 分類；下一回合轉向「完整 source extraction/codepage coverage」
的最小可驗證切片。
