# M1.32：selected code-unit → font-bank → renderer provenance

本回合只使用 M1.30 demon prefix 與 M1.31 skill prefix 已經 identity-anchored
的五個 field positions：demon 第一筆的三個字元位置，以及 skill 第一筆的兩個
字元位置。目標是把「已知 code-unit identity」接到實際 font-bank ROM block、
builder transform 與 named renderer；不把這五筆推廣成完整 codepage，也不重跑
OBJ/resource scan。沒有 runtime capture，沒有提交任何 font/source bytes。

## 可重現命令

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m132_font_edge.py \
  --rom /private/tmp/smt2-a5tj.gba \
  --output /private/tmp/smt2-m132-font-edge.json
```

工具輸出只有 function/address metadata、literal/call target、field/font block
hash、length/count、stable/reference ID 與 boolean status；不輸出 unit value、
字元、raw field、font bytes、decoded text、圖片或 translation ledger。

## Static transform chain

```
identity-anchored record field position
  -> 16-bit unit (private comparison only)
  -> bank[unit>>8] at 0x0815ed88, stride 0x08
  -> font_source = bank + ((low>>4)<<10) + ((low&0xf)<<5)
  -> source block +0x000 (0x20 bytes)
  -> source block +0x200 (0x20 bytes)
  -> 0x080abf24 byte swizzle
  -> 0x020391e0 scratch / paired destination +0x400
  -> 0x080ac218 small renderer
  -> 0x080aa1f4 writer callsite 0x080ac286
```

`0x080abf24..0x080ac0d2` builder boundary、`0x080ac218..0x080ac296` small
renderer boundary、四個 literal edge，以及 `0x080ac286`→`0x080aa1f4` BL target
均 match。builder 的每個 0x20-byte source block 產生 0x40-byte swizzled output；
工具以獨立 inverse transform 在 synthetic fixture 與五筆實際 bounded block
上驗證可逆。這是 static transform contract，不是畫面完成後的 snapshot。

ROM identity：8 MiB，SHA-256
`819a6a19a40bfbe7608f4b813dc18285c827f64e1523561ffe8e10ce8ab5991e`。

## Evidence 分層

### Confirmed

- `0x0815ed88` bank pointer、font source address expression、五筆 source block
  address/hash 與 paired `+0x200` block 均可重抽取。
- `0x080abf24` 的兩段 0x20→0x40 byte swizzle 已由逆變換驗證；五筆均通過
  identity、source availability 與 inverse transform contract。
- 五筆 static edge 已接到 `0x080ac218` renderer 與 `0x080aa1f4` writer callsite。

### Provisional

- 這是 selected static code-unit→font-block→renderer provenance；font block hash
  不是 rendered runtime pixel proof。
- `0x020391e0` 是 builder literal 的 scratch target；live cache contents、自然
  scene 與 DMA/OBJ timing 仍未捕捉。

### Unknown / blocked

- 未 anchor code units 的完整 Unicode/codepage、glyph set、width budget、control
  codes、font replacement 與可逆回插仍未知。
- runtime listener 的 socket blocker 仍存在，沒有把 synthetic 或 post-frame
  snapshot 當成 natural hit。
- source table、translation ledger、翻譯、encoder、BPS 與 runtime QA 仍 blocked。

下一步最小缺口是利用這條已確認的 font edge，建立不含 raw source 的 codepage/
width/control contract；若需要 runtime，僅對一筆已知 skill/demon anchor 做 fresh
mGBA bounded capture，否則先解析 `0x080aa1f4` writer 的 layout/width arguments，
不擴大 glyph 或 resource 掃描。
