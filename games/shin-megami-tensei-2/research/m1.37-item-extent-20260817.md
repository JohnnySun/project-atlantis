# M1.37：item family bounded full extent（2026-08-17）

本回合把 M1.36 的 item source/index producer 落到完整的 caller-addressable
window，沒有重做 graphics/resource 分類、全 ROM glyph scan 或 runtime navigation。
工具 `tools/m137_item_extent.py` 只輸出每筆 record 的 stable ID、address、field
hash、length、termination、unit-count 與 aggregate coverage；它不輸出 field bytes、
unit values、日文、glyph、圖片或 translation ledger。

## 可重現命令

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m137_item_extent.py \
  --rom /private/tmp/smt2-a5tj.gba \
  --output /private/tmp/smt2-m137-item-extent.json
```

ROM identity 先由 M1.36 的共用 gate 驗證：A5TJ、8 MiB、CRC32
`af40cc99`、SHA-256
`819a6a19a40bfbe7608f4b813dc18285c827f64e1523561ffe8e10ce8ab5991e`，exit `0`／
status `pass`。

## Confirmed

- table base `0x08198b74`、stride `0x24`、addressable ordinal `0x00..0xcf`，
  field `+0x14`、每筆 8 個 little-endian 16-bit units；完整 table window 為
  7488 bytes，208/208 records 與 208/208 fields 可重抽取。
- 208 筆 field 的 nonzero unit count 分布為 3/4/5/6/7/8 分別 18/29/39/27/50/45；
  163 筆在固定 field 內有 `0x0000`，45 筆使用完整 8-unit field。總 nonzero unit
  occurrence 為 1237，沒有 `0x0300`／`0x0301` 出現在這個 item field window。
- M1.28 的連續 0..7、M1.35 的 ordinal 8/`0x58`/`0x80`/`0xc0`，合計 11 個
  bounded identity anchors 經同一 ROM 重跑全部 match。外部 identity/order 只作
  cross-check，不取代 A5TJ field source；參考來源保留為 Nintendo manual、Wiki* item
  table 與既有 M1.28/M1.29 reference records：
  `https://www.nintendo.co.jp/data/software/manual/WUP-N-JBRJ-JPN.pdf`、
  `https://wikiwiki.jp/snes007/%E7%9C%9F%E3%83%BB%E5%A5%B3%E7%A5%9E%E8%BB%A2%E7%94%9F%E2%85%A1%E3%80%80%E5%90%84%E7%A8%AE%E3%83%AA%E3%82%B9%E3%83%88`。
- field window 是固定 16 bytes，且 M1.27/M1.33 已確認 consumer 會將 8 units
  複製至 stack、再附加 `0x0000`；因此本回合建立的是可重抽取 addressing／field
  contract，不是已完成的 Unicode decoder。

## Provisional / unknown

- `0x08198b74` 的 addressable extent 已 confirmed，但 208 筆全屬同一 semantic
  item category、子分類邊界與未錨定 record identity 尚未由逐筆獨立 reference 證明。
- 既有 42 個 anchored unit identity 只覆蓋 1237 次 occurrence 中的 673 次；另有
  564 次 occurrence 未映射。這不是 complete codepage，不能據此建立翻譯 ledger。
- item field 本身未觀察到 control unit；reader 的 `0x0300`／`0x0301` 規則與
  writer/layout contract 仍須在 private full extraction 中交叉，不能把「沒有 control
  unit」升格成全遊戲 control-code contract。
- M1.36 的 GDB listener blocker 仍維持 runtime unknown；本回合沒有 natural scene
  selection、RAM live value 或 mGBA QA。

## 下一個最小缺口

在 `/private/tmp` 或 ignored `work/` 建立 item-only private decoder/reference
cross-check：以 external item order 的 source hash 配對 208 個 stable IDs，逐步補足
item family 的 unit→Unicode identity，並將每個 mapping 分成 anchor／context-derived／
unmapped tier。提交區只保留 decoder contract、hash/count/status，不把完整 item names、
raw source 或 private decoded JSONL 帶入 Git；在 item family 的 codepage、width、
control and round-trip gate 仍未完成前，M2 ledger 保持 blocked。
