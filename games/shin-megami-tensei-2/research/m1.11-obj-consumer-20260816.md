# M1.11 OAM／OBJ consumer 與 source-class mapping（2026-08-16）

## 範圍與可重現命令

本回合只沿 M1.5／M1.6 已知的 OAM buffer、固定 OBJ DMA 與
`0x06010000` literal references 做 bounded static mapping。沒有重跑同一個
reset→Start negative window，沒有寫入 selector／RAM，也沒有做全 ROM glyph
pattern scan。報告只保存在 `/private/tmp`，不進 Git：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m111_obj_consumer.py \
  --rom /private/tmp/smt2-a5tj.gba \
  --output /private/tmp/smt2-m111-static.json
```

ROM SHA-256 仍為
`819a6a19a40bfbe7608f4b813dc18285c827f64e1523561ffe8e10ce8ab5991e`；工具
schema 為 `smt2.m1.11.obj-consumer.v1`。輸出欄位限於 address、function
boundary、length、hash、count、DMA 參數與 caller PC，不保存 instruction/data
bytes、raw tile、完整原文或 source table。

## Confirmed：OAM metadata consumer

`0x080a9af4` 的 Thumb function window hash 為
`d48d1b85a6406a711cf24a49a72585b91624970ffb4ce8a43509a5f62bed8f33`，bounded
first-return boundary length 為 202 bytes；DMA setup 從 `0x080a9b06` 到
`0x080a9b26`，長度 32 bytes，hash 為
`14bf2ae467c8230db433e113657f07cfd7af05027973272bb90e66ceb82d9c13`。反組譯與
literal pool 交叉得到：

| 欄位 | 值 |
| --- | --- |
| DMA register | `0x040000d4` |
| source | IWRAM `0x030033f0` |
| destination | OAM `0x07000000` |
| control | `0x84000100` |
| transfer units | `0x100` |
| 後續 callsite | `0x080a9b26 → 0x080aabc8` |

destination 不是 ROM literal；由 `movs 0xe0`／`lsl 19` 組成
`0x07000000`。`0x080aabc8` 的 callsite match 成功，沒有把
`0x080a9af4` 誤標成 `0x06013000` OBJ tile DMA。這條因果邊目前可命名為
`0x030033f0 → DMA3 → 0x07000000` 的 OAM attribute metadata consumer，不能
當作字型來源。

OAM buffer 相關 bounded nodes 為：

- `0x080a9dd0` (`oam_table_fill`)：first-return length 152、window hash
  `2fbcc96174b759f12d9fc5da2c6b47edd94dc10ec8fb271582a5c50be55a6149`，direct
  BL caller `0x080a974e`；讀取 `0x030033f0`、`0x030031e0`、`0x03002130`。
- `0x080a9e38` (`oam_base_copy_candidate`)：48-byte bounded window hash
  `3ed73e63c6f88f87c0e20fedc422b80b7eb6cc2cf4bad7b28330148eeb242313`，沒有
  direct BL caller；它落在前一個 function 的 fall-through／inline 範圍，不能
  獨立宣稱為函式，使用 `0x030033f0` 與 `0x030031f0`。
- `0x080a9ea8` (`oam_record_append`)：first-return length 92、window hash
  `d84c146618195bffb2d94592ae01c664b91d55945a8d0156f4c68dea22cc91de`，6 個
  direct BL callers：`0x080a9f96`、`0x080aa234`、`0x080aa340`、
  `0x080aa598`、`0x080aa8b0`、`0x080aaac8`；使用
  `0x03003950`、`0x03002130`、`0x030031e0`、`0x030031c8`。
- `0x080a9f04` (`oam_object_builder`)：first-return length 632、window hash
  `f2bf3e8b8fc928ca4fcdca38af3b290b7ec7853c69fdc7920fa968e13f3904a1`，direct
  BL callers `0x080aa1b0`、`0x080aa1e8`；在 bounded window 內讀取
  `0x030031f0`，並由 `0x080a9f96` 進入 record append。

這些 edge 只證明 OAM attribute staging／copy；沒有 source pointer、code-unit
或 glyph-writer provenance。

## Confirmed／provisional：OBJ VRAM destination family

`0x06010000` 有 12 個 bounded Thumb literal loads：
`0x080abd80`、`0x080ac1b0`、`0x080bd136`、`0x080c1350`、`0x080d1dfc`、
`0x080d5514`、`0x080d5e6e`、`0x080d5f8e`、`0x080d61f2`、`0x080d9a3e`、
`0x080dc6aa`、`0x0813efce`。工具為每個 reference 保留所屬 bounded function
entry／window hash／length 與 direct caller count；`0x080d61f2` 沒有可靠的
bounded Thumb prologue，故只保留 literal-load address，不虛構 function boundary。

八個已知 fixed `0x06013000` DMA sites 的 pattern 全部仍驗證成功：
`0x080baecc`、`0x080bb318`、`0x080bb61c`、`0x080bbcd8`、`0x080bc584`、
`0x080bc978`、`0x080d8d80`、`0x080d9448`。這只確認 destination family 與
固定 DMA 參數，不會把 source 自動命名為文字或字型；M1.6 的
reset→Start window 仍是八站 0 hit 的原始 bounded negative。

## 分層結論與下一個最小缺口

### Confirmed

- OAM `0x030033f0 → 0x07000000` 的 DMA3 consumer、參數與 function/callsite
  boundary。
- OAM table-fill、inline/fall-through copy、record append、object builder 的
  caller 與 RAM buffer 類別。
- `0x06010000` 的 12 個 literal references，以及 8 個 fixed
  `0x06013000` DMA pattern。

### Provisional

- `0x06010000` references 是 OBJ VRAM destination candidates；尚未證明每個
  reference 都會在免責畫面使用，也未取得其 source argument。
- fixed OBJ DMA 的 source class 仍是 runtime/resource candidate；不能由
  destination 或 OAM metadata 推回 codepage。

### Negative／blocked

- 本回合沒有 source pointer → code-unit → transform → OBJ tile → OAM 的新因果鏈。
- 沒有文字身份、codepage、控制碼、stable string ID 或可重抽取 source table。
- 翻譯 ledger、回插器、round-trip、BPS 與 runtime translation QA 仍封鎖。

下一個最小缺口是從這 12 個 `0x06010000` consumer 中選出可由自然 resource
transition 觸發且能觀察 source register 的單一 bounded edge；若仍只有 destination
metadata，才轉向另一個已命名的 code-unit／text consumer，不再擴大 OBJ 或 glyph
掃描。
