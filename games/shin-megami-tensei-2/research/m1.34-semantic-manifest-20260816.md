# M1.34：bounded semantic ID／unit manifest（2026-08-16）

本回合把 M1.28–M1.31 已完成的四個 identity anchor cohort 合併成一份
metadata-only manifest。它不重新掃描 ROM、不推導完整 table extent、不輸出
16-bit unit、日文原文、raw field、glyph 或 translation ledger；工具只是把既有
bounded probes 的 stable ID、field hash、長度、count、termination 與 match status
組合成可審核索引。

## 可重現命令

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m134_semantic_manifest.py \
  --rom /private/tmp/smt2-a5tj.gba \
  --output /private/tmp/smt2-m134-manifest.json
```

## Evidence 分層

### Confirmed

- 四個既有 source-family namespace 可在同一 A5TJ ROM 上重抽取。
- item 8、item boundary 3、demon 16、skill 32 的 identity boolean 全部 true；
  field hash、stable ID、record address/stride/offset 可重現。
- combined manifest 不含 raw source，且與 M1.28–M1.31 的 private identity hashes
  分離保存。

### Provisional

- 這是 59 筆 evidence cohort 的 semantic manifest，不是任何一個 family 的完整
  source table；item/demon/skill 中間 records 的語意不能由相鄰 anchor 猜測。
- 相同 code-unit 在不同 family 出現只表示各自 bounded external anchor match，
  不能升格成完整 Unicode/codepage map。

### Unknown / blocked

- item/demon/skill table extent、main script/event/system source table 與自然 runtime
  selection；未 anchor unit 的 Unicode identity、glyph/width/control 詳情。
- translation ledger、zh-TW 術語定稿、font replacement、encoder、BPS、round-trip
  與 runtime QA 仍未開始。

下一個最小缺口是從已命名 caller 對每個 family 選一個有限的「相鄰但尚未 anchor」
record，先確認 termination/field shape 與 stable ID 是否可連續抽取；若遇到
category boundary 或特殊 accessor 分支就保留 negative，不把連續位址當成語意證明。
