# M1.29：item equipment subcategory boundary anchors

日期：2026-08-16

## 範圍

本回合只讀 M1.28 已確認的 `0x08198b74` shared table 三個 sparse records：
ordinal `0x58`、`0x80`、`0xc0`。它們分別位於公開 item sequence 的槍械、頭部防具、
腳部防具段落；工具只在記憶體中做 code-unit identity comparison，提交的 report
只有 address/hash/length/count/reference/match，不含原文、unit values、圖片或 ledger。
沒有把未選取的 `0x70` 或 `0x08198eb4` secondary path 猜成文字。

可重現命令：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m129_item_boundaries.py \
  --rom /path/to/A5TJ.gba \
  --output /private/tmp/smt2-m129-item-boundaries.json
```

## 實際結果

- `0x08198b74`、stride `0x24`、field `+0x14` 的完整 caller-bounded table window
  仍為 7488 bytes，hash
  `77f7e001fcf190fdb7e6ed3018eab438e02d9a47e11630780f8dfb40eae5bdc8`。
- 三個 sparse anchor 全部 match：`0x58` 的公開 gun anchor、`0x80` 的 headgear
  anchor、`0xc0` 的 footgear-segment anchor。observed field unit counts 是
  `7, 5, 8`；三者均有 fixed field hash 與 `identity_match=true`。
- M1.28 的有限 map 加上本回合 boundary 字元後，共固定 42 個 custom unit identity；
  identity manifest hash 是
  `111e23ba58bfb229fd6e5cf43c04890a25e952d6b7b7e81cdd65dc7236e3462c`。這仍不是
  全遊戲 codepage。
- boundary tool 只輸出 `item-boundary-58-gun-start`、
  `item-boundary-80-headgear-start`、`item-boundary-c0-footgear-segment` 等
  reference ID，不輸出 anchor text 或 raw unit stream。

## Evidence 分層

### Confirmed

- 三個跨距較大的 item equipment boundary anchor 都由同一 custom-unit map 精確
  對上公開日文 sequence，支持 `0x08198b74` 前綴確實不是任意 text-like data。
- `m29-item-record-{ordinal:04d}` 仍可由固定 table base/stride/field 重抽取。

### Provisional

- 三個 boundary 只確認 sparse semantic edges，沒有宣稱中間每筆 record 的 exact
  subcategory，也沒有宣稱整個 208 筆 table 的所有 record 都已完成 category mapping。
- GBA item 對照的公開資料包含不同版本資料表；本回合只把日文說明書與社群順序當
  identity/order cross-check，未把外部名稱直接提交為 A5TJ source。

### Negative / unknown

- `0x70` 等尚未有獨立 identity anchor 的特殊 field 保持 unknown；沒有以短 field
  或高 bank byte 猜測其文字。
- secondary `0x20` accessor、自然 runtime selector、完整 codepage、glyph、
  control/width 與回插契約仍未知；M2 ledger gate 維持 blocked。
