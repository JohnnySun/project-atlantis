# M1.30：demon record prefix 的 code-unit identity cross-map

本回合承接 M1.27 已命名的 16-bit reader caller，但切換到另一個獨立
record family。目標是確認 `0x080bf648` accessor 的 table target 與少量
record 語意，不把 item、skill、demon、劇情或 system data 混成同一張 source
table。這是唯讀 bounded static slice；沒有 mGBA runtime capture，也沒有建立
translation ledger。

## 可重現命令

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m130_demon_crossmap.py \
  --rom /private/tmp/smt2-a5tj.gba \
  --output /private/tmp/smt2-m130-demon-crossmap.json
```

輸出只包含 address、Thumb boundary、literal target、callsite target、field
hash、length/count、stable ID、reference ID 與 match metadata；不輸出 record
bytes、16-bit unit、decoded 日文、glyph、圖片或 ledger。工具也明確把 table
extent 設為 unknown，不把 accessor 中 probe 範圍外的特殊 index 當成 record
count。

## Static provenance

- accessor `0x080bf648..0x080bf6ce` 的 `0x080bf656` Thumb literal load 讀到
  `0x0819cb74`；boundary、`push`/`pop`/`bx` 與 literal pool 交叉成立。
- caller `0x080e1644..0x080e17f2` 的 boundary 交叉成立。它在 object
  `+0x26` 讀最多五個 ID slot，於 `0x080e1746` 呼叫 accessor；回傳 record
  的 `+0x22` field 固定複製八個 16-bit unit 到 stack `+0x0c`，追加
  `0x0000`，再依分支於 `0x080e17a6`／`0x080e17cc` 呼叫
  `0x080ac3ac`／`0x080ac334`。
- ROM direct-BL scan 找到 caller wrappers `0x080e17fc`、`0x080e1810`；
  這只確認 static call graph，不是自然 runtime scene proof。accessor 還有
  其他 direct callers，但本回合不把它們當作已觸發的 selection。
- accessor 的 bounded addressing contract 是
  `record = 0x0819cb74 + index * 0x60`、field `+0x22`、最多八個 halfword。
  probe 只取 ordinal `0..15`，沒有宣稱完整 table extent；已知 accessor
  內的特殊 index `0x106`、`0x109`、`0x10c` 留在 unknown 分層。

ROM identity：8 MiB，SHA-256
`819a6a19a40bfbe7608f4b813dc18285c827f64e1523561ffe8e10ce8ab5991e`。

## Identity result

以三個互相獨立的日文資料來源作為順序／名稱 identity anchor：GBA 惡魔辭典、
日文系列資料表，以及獨立的 SMT II 惡魔資料庫。工具內只保留 16 筆 bounded
anchor 的比較資料，報告不輸出 anchor text。ordinal `0..15` 的 field length
分別是 `3,5,4,4,4,5,4,4,5,4,5,4,6,6,5,5`，16/16 identity match；每筆
各有可重抽取的 field hash，stable ID formula 為
`m30-demon-record-{ordinal:04d}`。本回合只保留 38 個 anchor-required custom
units；bounded identity manifest hash 為
`7063d994d4a51e76d28daedb283f4d228c3707444f5c741128621962720d78e9`。

這是目前第一條由已命名 accessor、固定 field 與外部 demon sequence 共同支持
的 demon code-unit edge。它確認的是前綴 family identity 與 addressing，不是
完整 codepage 或 Unicode map；item 的 `m28`／`m29` namespace 仍完全分開。

## Evidence 分層

### Confirmed

- accessor literal、兩個 Thumb function boundary 與三個 BL callsite target
  均 match。
- `0x0819cb74`、stride `0x60`、field `+0x22` 的 ordinal `0..15` 連續 16 筆
  record 均對上外部 demon sequence。
- `m30-demon-record-{ordinal:04d}` 是可重抽取的 table-local addressing ID；
  這 16 筆是 demon family 的 bounded code-unit identity edge。

### Provisional

- `0x0819cb74` 的完整 table extent、demon category spans、特殊 index 作用與
  其餘 record 語意仍未證明。
- 工具內的有限 custom unit map 只服務這 16 筆 anchors，不是本作完整 codepage。

### Unknown / blocked

- 尚無自然 runtime selection、live reader argument 或 mGBA scene capture。
- 尚未確認未 anchor unit 的 Unicode/glyph identity、寬度、控制碼與可逆回插。
- source table、translation ledger、翻譯與 patch 工程仍 blocked；本回合不開始
  翻譯。
