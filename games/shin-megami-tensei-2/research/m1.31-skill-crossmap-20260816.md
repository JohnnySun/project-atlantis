# M1.31：skill record prefix 的 code-unit identity cross-map

本回合沿 M1.27 的 named reader family，選擇相鄰但獨立的 leaf accessor
`0x080bf5c0`。它以 `index * 0x1c` 取得 `0x0819b9f4` record，caller
`0x080bf5d8` 再從 record `+0x06` 消費最多八個 halfword，交給
`0x080ac218` small renderer。這是唯讀 bounded static slice；沒有 runtime
capture、沒有 graphics/resource 分類、沒有建立 translation ledger。

## 可重現命令

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m131_skill_crossmap.py \
  --rom /private/tmp/smt2-a5tj.gba \
  --output /private/tmp/smt2-m131-skill-crossmap.json
```

工具只輸出 address、Thumb boundary、literal/call target、field hash、
length/count、stable ID、reference ID 與 match metadata；不輸出 record bytes、
16-bit unit、decoded 日文、glyph、圖片或完整 codepage。外部日文名稱只留在
bounded private comparison，沒有作為 source table 或翻譯文字提交。

## Static provenance

- `0x080bf5c0` 是 leaf accessor，`0x080bf5d0` 的 `bx lr` 給出
  `0x080bf5d2` boundary；`0x080bf5cc` literal load 指向 `0x0819b9f4`。
  `0x080bf5c0` 以 Thumb arithmetic 形成 `table_base + index * 0x1c`。
- `0x080bf5d8..0x080bf648` caller boundary 交叉成立；`0x080bf606` 呼叫
  accessor，回傳 record `+0x06` 開始逐項讀取，最多八個 16-bit unit，以
  `0x0000` 或八項作 bounded termination。
- `0x080bf620` 的 BL target 是 `0x080ac218` small renderer；這條 path 與
  M1.30 demon／M1.28–M1.29 item accessor 的 table/namespace 分開。
- direct-BL index 只當 static call graph metadata；本回合沒有把其他 caller
  當成自然 runtime selection，也沒有 synthetic table/state write。

ROM identity：8 MiB，SHA-256
`819a6a19a40bfbe7608f4b813dc18285c827f64e1523561ffe8e10ce8ab5991e`。

## Identity result

以三個獨立層次的日文資料作為 identity/order cross-check：PS 版魔法表、SFC
參考資料的「仲魔特技表」，以及 GBA 惡魔資料頁中實際出現的技能名稱。工具只
比較 ordinal `0..31` 的連續 32 筆 prefix；每筆 field length 分別為
`2,4,4,6,2,4,5,6,2,4,4,6,2,3,4,5,6,3,6,5,4,4,4,6,5,2,4,3,4,4,4,4`，
32/32 identity match。每筆都有可重抽取 field hash，stable ID formula 是
`m31-skill-record-{ordinal:04d}`；32 個 anchor-required custom units 的
identity manifest hash 是
`7e3f85aaef246fe3c18f333df8b5ff32b2d3900c8a3bce141864aad6b32d7076`。

這是第二條獨立 accessor 與第三個已命名 data family 的 code-unit edge，確認
`0x0819b9f4` 前綴是 skill record family。它不代表完整 skill table extent、
完整 codepage、Unicode、字寬、控制碼或回插規則。

## Evidence 分層

### Confirmed

- leaf accessor boundary、literal target `0x0819b9f4`、`index * 0x1c` formula、
  caller boundary 與兩個 BL callsite 均 match。
- ordinal `0..31` 的 32 個連續 record field 均對上外部 skill sequence。
- `m31-skill-record-{ordinal:04d}` 是可重抽取的 skill table-local addressing
  ID；skill、demon、item 三個 namespace 維持分離。

### Provisional

- `0x0819b9f4` 的完整 table extent、skill category spans 與 probe 範圍外的
  records 尚未證明。
- 有限 custom unit map 只服務 32 筆 anchors，不是完整 game codepage。

### Unknown / blocked

- 尚無自然 runtime skill selector、record index 或 live renderer argument。
- 未 anchor unit 的 Unicode/glyph identity、完整控制碼、字寬、font replacement
  與可逆回插仍未知。
- source table、translation ledger、翻譯與 patch 工程仍 blocked。
