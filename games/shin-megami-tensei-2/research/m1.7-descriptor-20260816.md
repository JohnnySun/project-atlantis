# M1.7 descriptor selection、間接 dispatch 與 producer 證據（2026-08-16）

本回合只保留 A5TJ 的位址、函式邊界、寄存器 metadata、長度、hash、count
與 bounded negative。ROM、savestate、完整原文、raw RAM/VRAM/OAM、tile bytes
與圖片均留在本機 `/private/tmp`，不進 Git；沒有建立 source table、ledger 或
翻譯。

## 方法與界線

- ROM 身分為 `DDS_2`／`A5TJ`、8 MiB，SHA-256
  `819a6a19a40bfbe7608f4b813dc18285c827f64e1523561ffe8e10ce8ab5991e`。
- 靜態工具為 `tools/m17_descriptor_probe.py --static-only`。它只讀取 bounded
  literal／pointer／callback window，輸出 address、offset、hash、count 與解析
  metadata；沒有重做全 ROM glyph pattern scan。
- runtime 使用 core `core/gba/gdbstub_client.py` 與本 session 的 mGBA 0.10.5
  GDB `2367`。自然 transition 的 bounded window 為 60 秒、700 stops、
  `a,start,a,b,down,a`，lean 模式保留 selector、queue producer、indirect
  trampoline、writer、LZ77、staging 與 KEYINPUT 路徑，避免 DMA/display watches
  吃掉輸入窗口。
- 另有一個明確標記的 synthetic fallback：在 KEYINPUT consumer stop 後以 GDB
  register/PC override 暫時呼叫 `group=1,index=7`，selector return 進
  fail-closed guard，不恢復 host context、不繼續執行遊戲。它只用來驗證選中的
  descriptor 是否真的進 producer，不能替代自然 resource transition。

## Static selector 與資料 ref（confirmed）

`0x080ba8d8` 是合法 Thumb function，entry halfword `0xb500`、terminal
`BX LR` 在 `0x080ba91a`，end exclusive `0x080ba91c`；跨越三段 code 與兩個
embedded literal pool 的 code hash 為
`2773e78c163d1323c1ba0c33bbc615fa5abf3e43885cbabdff1e7f8a01775776`。literal
pool 位於 `0x080ba8e8`、`0x080ba908`–`0x080ba910` 及 null branch 使用的
`0x080ba91c`，ARM7TDMI Thumb boundary、literal target 與 callsite 交叉一致。

selector 的資料流是：

```text
original r1 low16 -> selector index
original r0 == 0  -> table 0x08182b20
original r0 != 0  -> table 0x08182b54
table[index]      -> descriptor pointer
descriptor        -> 0x080ad0fc(descriptor, 0xffff)
queue handle      -> global 0x0300463c
```

因此 `0x08182b70` 不是獨立 source table；它是
`0x08182b54 + 7*4`，該 entry 的 value 是 `0x081869c8`。這把 descriptor/data
ref 與 selector operation 接起來，但尚未表示自然遊戲狀態已選到 index 7。

三個 direct Thumb BL caller 都通過 ARM7TDMI function boundary、literal pool
與 BL target 驗證：

| function | BL site | group | selector argument | boundary |
| --- | --- | ---: | --- | --- |
| `0x08138fb8`–`0x08138fdc` | `0x08138fd0` | 0 | `halfword[*(0x03006950) + 2 * halfword[0x0203db40]]` | prologue/`BX LR` |
| `0x08139040`–`0x0813906a` | `0x08139058` | 1 | 同上 runtime halfword table | prologue/`BX LR` |
| `0x0813a8b8`–`0x0813a8d8` | `0x0813a8c6` | 1 | constant `1` | prologue/`BX LR` |

全 ROM bounded Thumb-2 BL decode 沒有其他 selector direct caller。三個 caller
function 本身沒有 direct BL caller，各有一個 Thumb pointer ref（分別位於
runtime `0x087917f4`、`0x087917fc`、`0x087918c8` 的 ROM function-pointer
region）；這是 indirect state dispatch evidence，不把它誤列成 direct call。

## Descriptor／callback layout（confirmed with bounded qualification）

`0x081869c8` 到下一個 pointer-table entry `0x08186c34` 是 620 bytes／155
words，window hash 為
`bf62476a475b1bfd60904417285c0855d96b53ced3a1226dddc8545950803c2c`。它不是
固定 stride record；是 callback opcode、opcode-specific payload 與
`0x10241224` sentinel 組成的 variable-length stream。window 內 sentinel 有
6 個，位址為 `0x081869e8`、`0x08186a38`、`0x08186a68`、`0x08186b30`、
`0x08186b74`、`0x08186bd8`。第一段可依 callback contract 從
`0x081869c8` 解到 `0x081869e8`：4 個 command，之後以 sentinel 結束；sentinel
後的 state/header 需要 live queue entry context，工具不把它猜成固定 record
stride。

generic callback table 在 `0x0815eeec`，25 entries、8-byte stride，bounded
table end `0x0815efb4`，table hash
`9b28bd4b1ba2a460cc1cc95955fca1c132cdb7587b404bbe2eab2c868d26673f`。queue
drain 以 `opcode << 3` 選 callback pointer，pointer field 在 entry offset 0，
再經 `0x0815cccc: BX r3` 間接呼叫。對本 descriptor window 重要的 callback
contract 已由 progress/cursor load 交叉得到：opcode `0x0a` consume 1 word、
`0x0b` consume 2、`0x0e` consume 5、`0x12` consume 3、`0x14` consume 1；
其餘 conditional/fixed helpers 不被強行套成同一 stride。

window 有 26 個 ROM Thumb function-pointer refs；其中 `0x080baef1`（實際
entry `0x080baef0`）出現 1 次，`0x080bafb9`（實際 entry `0x080bafb8`）出現
4 次。這只確認它們是 descriptor payload function pointers，不確認其中任何
一個已在自然畫面被執行。bounded entry cross-check 也保留在工具輸出：
`0x080baef0` prologue halfword `0xb510`、window hash
`710ff67ace9c816e59d579cae0fab5b1744fddbeb516e72161b0a255e560c131`；
`0x080bafb8` prologue `0xb570`、bounded hash
`0a9b1f874c4d997295729e1221e96c6e8acfeb1f423e77b461eb212b1907c923`；
`0x0815cccc` trampoline halfword `0x4718`、two-byte hash
`477db9ac7ca5efc12e37f882656b8fe5a363ffeb99b2e565a953d10c3c91ab21`。
這些是 ARM7TDMI Thumb entry/dispatch boundary 證據，不是自然 source identity。

## Runtime evidence

### Natural resource transition（confirmed negative for this window）

自然 transition report（留在 `/private/tmp/smt2-m17-runtime-lean-2.json`）有
38 次 KEYINPUT read、實際送出 A／Start／A／B 的 bounded key phases；generic
resource queue 有 producer 2 hits，source 為 `0x08509cf8` 與 `0x08509cd0`。
`0x0815cccc` 有 101 次 indirect stop；ROM target 只有既有 resource/event
callbacks（5 個 distinct target），不是 `0x080baef0` 或 `0x080bafb8`。

本窗口 selector 的三個 callsite 與 entry 均為 0 hit；`0x080baef0` staging
candidate、`0x080bafb8` mode writer、`0x02001000` staging write 也為 0 hit。
唯一 LZ77 wrapper hit 是 source `0x084f9cd0`、destination `0x0200f874`、
decoded length 2624，與先前 reset→Start formal queue activity 相同，並非
`0x02001000`。這是「A/Start/方向鍵 natural transition」的 bounded negative，
不是全遊戲 negative，也不是 codepage/font 解決證明。

### Synthetic selector index 7（confirmed producer link; not natural selection）

fail-closed report（`/private/tmp/smt2-m17-runtime-force7-final.json`）在
KEYINPUT consumer `0x080a9a0a` stop 後注入 `group=1,index=7`：

- 靜態 table lookup 選到 `0x081869c8`；live `0x0203db40` counter 是 0，live
  `*(0x03006950)` 目前也是 0，說明 fresh boot 尚未初始化自然 caller 使用的
  halfword dispatch table。
- selector 後 `0x080ad0fc` 真的命中，PC `0x080ad0fc`、LR `0x080ba901`，
  `r0=0x081869c8`、`r1=0xffff`；這是 descriptor → queue producer 的 runtime
  因果鏈，不是只看 ROM table ref。
- return guard `0x080ad2e0` 命中後立即停住，`resumed_host_context=false`。
  因此這個回合沒有宣稱 descriptor command 已自然 drain，也沒有把
  `0x080baef0`／`0x080bafb8` 升格為 writer。

先前同一種 fail-closed full-watch capture 也在 producer 同步寫入時觀察到
queue slot `0x02009068`／`0x020090cc` 的 metadata，原有 resource source 仍是
`0x08509cf8`／`0x08509cd0`；synthetic descriptor producer 本身沒有繼續到
glyph writer。一次嘗試把 synthetic return 再改跳 `0x080ad01c` 的 force-drain
在 `0x080ad028` 停於 synthetic unknown breakpoint，故不把它當自然 callback
證據，也不再擴大 emulator override。

## 分類與下一個最小缺口

- **confirmed**：selector function boundary/literals；`0x08182b70` 的
  table-index-7 意義；三個 direct callsites；25×8 callback table 與 relevant
  payload advance；descriptor bounded sentinel stream；synthetic
  `0x081869c8 → 0x080ad0fc` producer link。
- **provisional**：sentinel 後各 state/header 的完整欄位意義；descriptor 中
  `0x080baef0`／`0x080bafb8` 是否是本作 glyph path；任何 glyph transform、
  source table、code-unit 或 Unicode identity。
- **negative（有界）**：自然 A/Start/方向鍵 transition 未命中 selector、三個
  caller、staging writer、mode writer、staging buffer；fresh boot live selector
  table pointer/counter 尚未初始化；synthetic force-drain 未取得可繼續採信的
  descriptor callback。
- **blocked**：尚未取得真正 source/index/code-unit argument，也沒有
  staging→OBJ VRAM→OAM 因果鏈；不建立 source table、stable string ID、codepage
  或翻譯批次。

下一個最小切片是對 `0x03006950` 做 reset 前 write watch，找到它由哪個 state
dispatcher 初始化，再使用該已初始化 table index 觸發 `0x08138fb8`／
`0x08139040` 的 caller；若自然 transition 仍不可到達，沿該 RAM table
initializer 向上 1–3 層取得 ROM state-table pointer，而不是再掃 glyph bytes。
