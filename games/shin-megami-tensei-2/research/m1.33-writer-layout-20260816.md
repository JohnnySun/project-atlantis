# M1.33：named text writer、控制碼與 layout contract（2026-08-16）

本回合只承接 M1.18/M1.32 已命名的 16-bit reader、font renderer 與
`0x080aa1f4`。目標是把「code-unit reader 的 cursor step／control branch」和
「descriptor → OAM attribute writer」分開確認。沒有 runtime capture，沒有掃描
其他 graphics/resource class，也沒有提交 ROM、instruction bytes、OAM bytes、
font bytes、完整日文或 translation ledger。

## 可重現命令

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m133_writer_contract.py \
  --rom /private/tmp/smt2-a5tj.gba \
  --output /private/tmp/smt2-m133-writer.json
```

工具輸出只有 address、PC/callsite、literal/value metadata、function hash、
length/count、mask 與 boolean status。`_synthetic_roundtrip()` 使用獨立 fixture
測試 modulo field；fixture 本身不寫入 report。

重要 call edges 均 match：

- `0x080aa234 → 0x080a9ea8`：writer 以 slot low byte 取得 OAM record。
- `0x080ac286 → 0x080aa1f4`、`0x080ac318 → 0x080aa1f4`：small／large renderer
  共用 writer。
- `0x080ac37e → 0x080ac218`、`0x080ac40a → 0x080ac2a0`：small／large reader
  對應 renderer。
- `0x080ac274` 與 `0x080ac306` 的 literal 都是 descriptor
  `0x0815ee18`。writer 的 direct caller index 有 47 筆；本回合只把上述已命名
  callsite 作為主 edge，不把其餘 callers 自動分類成文字。

writer 中間的 literal pool 分成兩段：`0x080aa288`／`0x080aa28c`／
`0x080aa290` 提供 `0x7fff`、`0x01ff`、`0xfffffe00`；`0x080aa2d4`／
`0x080aa2d8` 提供 `0x03ff`、`0xfffffc00`。這些 mask 與每一個 field 的
load/add/store pattern 都由工具逐一檢查，不依賴把 pool 內容當成指令。

## Confirmed writer layout

`0x080aa1f4` 先從 `r0` 指向的 descriptor 複製三個 halfword 到 6-byte OAM
record，再套用下列有限欄位。這是 OAM metadata layout，不是 Unicode 或文字
來源表：

| writer input | OAM effect | 可逆範圍 |
| --- | --- | --- |
| `r0` descriptor pointer | template `attr0/attr1/attr2` at offsets `0/2/4` | 由同一 template 重建 |
| `r1` | low 8 bits 選 OAM slot | slot identity 是外部 key |
| `r2` | `attr2` high nibble 加法 | modulo `0x10` |
| `r3` | low 2 bits 寫入 `attr2` bits `10..11`；high nibble `0x8000` 分支控制 `attr1` bit 12 | flags modulo `4` 加一個 mode bit |
| stack `+0` | `attr2` low 10 bits 加法 | modulo `0x400` |
| stack `+4` | `attr1` low 9 bits 加法；`0x8000` mode 另外控制 bit 12 | modulo `0x200` 加一個 mode bit |
| stack `+8` | `attr0` low byte 加法 | modulo `0x100` |

因此本回合可安全建立的是「descriptor template + bounded modulo fields」的
encoder contract；不是把所有 OAM record 反推出字串。工具的 synthetic fixture
六個欄位均 inverse round-trip，manifest hash 為
`086025b58b58f3709c58284b7d3cde9e44d485a9908e914a9ac441ee69f7ad64`。

## Confirmed reader control／cursor contract

small／large reader 都以 `ldrh` 讀 unit、每次前進 2 bytes，並且在 bounded
function path 內有相同的三分支：

| unit | action |
| --- | --- |
| `0x0000` | stop |
| `0x0301` | stop；兩個 reader 都有 literal compare |
| `0x0300` | line-break branch，不呼叫 glyph renderer；base 加一步、cursor reset |
| 其他 nonzero unit | 呼叫對應 renderer |

cursor step 不是依 Unicode unit 查表：small reader 從 caller stack
`entry+0x28` 取 low16，large reader 從 caller stack `entry+0x30` 取 low16；
一般 glyph path 將 cursor 加此 step，line-break path 將 base 加此 step 並把
cursor 還原。這確認了 A5TJ reader 的固定 caller-supplied layout advance，
但不能把它直接命名成所有畫面的像素字寬；實際 screen fit、descriptor 變體與
zh-TW replacement glyph budget 仍待 scene/runtime 或更多已命名 caller 證據。

## Evidence 分層

### Confirmed

- writer／allocator／small／large renderer／small／large reader 的 Thumb boundary、
  return candidate、bounded hash 與 selected callsites。
- descriptor 三個 halfword → OAM record 的 field mapping、mask、modulo inverse。
- `0x0300` line break、`0x0000`/`0x0301` termination、16-bit unit/2-byte advance，
  以及 caller-supplied fixed cursor step。

### Provisional

- cursor step 是 layout advance；本回合沒有把它升格為所有字元相同的 pixel width。
- OAM attr1/attr0 的實際螢幕軸向與 descriptor template 的每個場景語意仍需自然
  runtime 或明確 scene caller 交叉。

### Unknown / blocked

- 完整主劇情／系統 source table、完整 codepage、未 anchor unit 的 Unicode identity。
- zh-TW 字庫替換、實際 pixel fit、自然 runtime writer arguments、完整回插與 BPS。
- M2 translation ledger 仍 blocked；本回合沒有建立 source table、翻譯或 patch。
