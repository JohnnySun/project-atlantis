# M1.17：第一條命名文字 consumer 邊（2026-08-16）

## 範圍

本切片不再掃描全 ROM glyph pattern，也不把 M1.15 的 128 筆 Huff→LZ77
resource set 當成文字來源。`tools/m117_text_consumer.py` 只驗證一條已由
靜態反組譯命名的 byte-table reader、其 descriptor dispatch，以及固定的
bounded table prefix。輸出只有地址、函式邊界、hash、長度、分類與 count；不輸出
ROM bytes、完整日文、圖片或 translation ledger。

## 可重現命令

```sh
PYTHONDONTWRITEBYTECODE=1 python3 \
  games/shin-megami-tensei-2/tools/m117_text_consumer.py \
  --rom /private/tmp/smt2-a5tj.gba \
  --output /private/tmp/smt2-m117-text-consumer.json
```

測試：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 \
  -m unittest games.shin-megami-tensei-2.tools.test_m117_text_consumer
```

## 確認的 source/index/code-unit 邊

靜態證據形成以下有限鏈：

```text
ROM 0x08163444
  + record_index * 0x0a
  -> 0x080b6460
  -> ldrb byte unit, loop until 0x20
  -> callsite 0x080b64e4
  -> descriptor pointer 0x08163638
  -> 0x080aa1f4 descriptor/OAM-record writer candidate
```

`0x080b6460` 先從 object field `+0x24` 取 index，再以
`index * 4 + index` 後乘 2 得到固定 10-byte record stride。讀取迴圈以
byte unit 消費記錄，遇到 `0x20` 停止；這是第一個已確認的 code-unit consumer，
但不是日文 codepage 或完整劇情 source table。

`0x080b6476` 的 Thumb literal load 指向 `0x08163444`；`0x080b64dc` 的
literal load 指向 `0x08163638`。`0x080b64e4` 的 Thumb BL 目標為
`0x080aa1f4`。兩個函式的 prologue、return candidate、bounded window hash
均由工具重算，並以 callsite/literal 交叉驗證。鄰近的同 base literal load
`0x080b6378`、`0x080b6576` 只列為相關 reader，尚未合併成同一語意。

## 有界資料分類

只驗證 `0x08163444` 起始的 37 筆、每筆 10 bytes 的 ASCII/padding-class
prefix（span `37 * 0x0a`）。工具保留每筆的 address/hash/length、space offset、
zero count 與 byte class count，不保留任何字串。prefix 之後的資料未分類，不能
據此宣稱整個表都是 label，也不能把這批英數 byte 當作日文翻譯來源。

## 證據分層

- **confirmed**：table base `0x08163444`、stride `0x0a`、object-field index
  addressing、byte-unit reader、`0x20` terminator、dispatch callsite、
  descriptor literal `0x08163638` 與 `0x080aa1f4` 的 Thumb edge。
- **provisional**：bounded prefix 屬於 ASCII padded UI/map-label 類；
  `0x080aa1f4` 是 descriptor 到 OAM record writer 的候選 consumer。
- **unknown**：日文主劇情 source table、codepage、control codes、Unicode／
  glyph identity、自然 runtime selector 到 record 的觸發、以及此文字 edge 的
  staging→OBJ VRAM 因果鏈。
- **negative for this slice**：沒有建立翻譯 ledger、source table 或回插資料。

因此下一步應從相同 reader family 的明確 table/category mapping，或已命名的
日文 code-unit producer 向上追 source pointer／index；不要回到 graphics resource
數量或全 ROM glyph 掃描。翻譯仍 blocked。
