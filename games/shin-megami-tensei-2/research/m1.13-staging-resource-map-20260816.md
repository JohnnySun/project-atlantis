# M1.13 staging writer／resource record map（2026-08-16）

## 範圍與重現

本回合只追已知的 `0x02001000` OBJ staging edge、其 Huff/LZ77 wrapper、以及
精確的 Thumb callback pointer `0x0813ef65`。沒有重跑全 ROM glyph pattern scan，
也沒有輸出 raw tile、解壓 payload、完整日文或 source table。

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m113_staging_resource_map.py \
  --rom /private/tmp/smt2-a5tj.gba \
  --output /private/tmp/smt2-m113-static.json
```

輸出只含 address、region class、function boundary、caller、length、hash、field
count 與分類 metadata。ROM identity 仍以 `research/recon-20260816.md` 為準。

## Confirmed

- `0x0813ef64` 是 34-byte Thumb function，第一個 `BX LR` 在 `0x0813ef84`，
  window SHA-256 為
  `ff915092997fe1e352f938e17de2c6e13a4fa78c56436f265a906c9575344f33`。
  它把 incoming `r1` 傳給 `0x0815cafc` 的 SWI `0x13` Huff wrapper，目的地為
  `0x0200afc8`；再把 incoming `r2 << 12` 加到 `0x02001000`，將中間結果傳給
  `0x0815cb00` 的 SWI `0x11` LZ77-WRAM wrapper。這證明一條可逆的
  Huff→LZ77 staging transform，但尚未證明輸入是文字。
- `0x0813ef65` 精確 Thumb pointer 在 ROM 中有 128 次 occurrence，組成 16 組、
  每組 8 筆、stride `0x18`、span `0xc0` 的 bounded record candidates。每筆
  的 `+0` 是 callback，`+4` 是 ROM-pointer-shaped source 欄位，`+8/+0xc/+0x10`
  是 bounded scalar fields；16 組的 span hash、長度與 source-region/count 已
  寫入機器可重跑的 JSON metadata。
- 每一組 8 筆的 source 欄位都落在 ROM region；每組 source-header marker 的
  low byte 都是 `0x24`。這只是反覆出現的分類訊號，不把它命名成標準 GBA
  壓縮 header，也不把 record group 命名成文字表。
- `0x080bd0e0` 是一個獨立 resource initializer candidate：靜態鏈為 ROM
  `0x08194c78` → Huff intermediate `0x0200afc8` → LZ77-WRAM destination
  `0x02000000`，並在 `0x080bd10c`、`0x080bd182` 註冊 type `1` callback。
  `0x0813efb4` 另註冊 `0x0813ef91` 與 `0x0813efc9`；後者是既知的
  `0x02001000 → 0x06010000` DMA helper pointer。

## Provisional／unknown

- record groups 很可能是 resource/asset dispatch candidates，但目前沒有從
  record reader 或 indirect call 取得 source index、code-unit、string ID 或
  glyph identity；`+4` 僅能稱為 ROM-pointer-shaped source field。
- `incoming r1` 可稱為 Huff source pointer candidate，`incoming r2` 可稱為
  12-bit output-bank/index candidate；這是依 function data flow 的暫定命名，
  不是自然 runtime argument provenance。
- 尚未把任何一筆 source pointer 連到 `0x02001000` staging bytes、OBJ VRAM
  tile、OAM entry 或已知畫面文字位置，因此沒有 confirmed glyph identity，
  也沒有推導 codepage、font stride 或 stable string ID。

## Negative／邊界

- 本回合未宣稱 runtime hit：既有本作 bounded GDB probe 的 mGBA listener 在
  attach 前受本機 socket／port 環境阻擋；這是工具環境 blocker，不是遊戲路徑
  的 negative evidence。報告中的 `no_natural_runtime_hit_due_listener_blocker`
  只記錄這個邊界。
- 因此沒有將 `0x0813ef65` record candidates 升格為文字 source table，沒有
  建立翻譯 ledger，也沒有開始翻譯或回插。下一個最小切片是辨識這 16×8 record
  candidates 的 bounded indirect reader／BLX dispatch，優先取得實際 callback
  的 source/index argument；若仍無法接通，再保留完整 static mapping 並轉向已
  命名的 text/code-unit consumer。
