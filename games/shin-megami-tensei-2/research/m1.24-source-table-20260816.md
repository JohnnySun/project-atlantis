# M1.24：bounded 16-bit source table 與可重抽取 unit contract

本切片只重放 M1.18 已命名的 `0x085861c8` pointer table；沒有掃描其他 ROM
region、沒有輸出 16-bit unit 值或 raw source，也沒有建立 translation ledger。

## Reproducible scope

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m124_source_table.py \
  --rom /path/to/A5TJ.gba \
  --output /private/tmp/smt2-m124-source-table.json
```

工具固定 `28` records、stride `0x08`、pointer field `+0x04`，每個 pointer 最多
讀 `0x100` bytes，直到 `0x0301`／`0x0000` 或 bounded window 結束。每筆以 table
ordinal 建立 `m18-record-0001` … `m18-record-0028` stable local ID，並驗證 record
field 的低 byte 與 ordinal 一致；其他 record metadata bytes 只保留數值欄位，尚未
替它們命名語意。

## Result

- table window、各 record address、pointer address、unit-stream hash、length、unit
  count、`0x0300` count、`0x0301` count、termination class 與 font-bank count
  都能重抽取。
- 28/28 record IDs 符合 ordinal，28/28 pointer 在 ROM 範圍，28/28 bounded stream
  都以 `0x0301` 結束；本 family 的 zero unit count 不被當成文字 terminator。
- reader／font builder 的 unit contract 可接回 M1.18：16-bit unit 每次 `+2`，高
  byte 選 `0x0815ed88` 的 `0x08`-stride bank pointer，低 byte 以
  `((low>>4)<<10)+((low&0xf)<<5)` 取 `0x20`-byte glyph source block。這是地址
  可逆性，不是 Unicode identity。
- bounded source data 位於 `0x08009aea` 起的 ROM data region；該位置與 table
  address/provenance 已記錄，未把它直接命名為主劇情、惡魔、技能、道具或系統表。

## Gate status

Confirmed：stable local ID、table stride/pointer field、16-bit unit advance、line
break `0x0300`、terminator `0x0301`、bounded source hash 與 font-bank addressing。

Provisional：28 筆是同一 encoded-string family candidate；record ID 是 table-local
identity，尚非 scene/category semantic ID。

Unknown：custom codepage/Unicode mapping、font glyph identity、字寬、record metadata
bytes 語意、自然 scene、與主劇情／事件／惡魔／技能／道具／系統資料的關係，以及
zh-TW encoder/font replacement contract。M2 translation ledger、source translation
與回插仍 blocked。

下一個最小缺口是從這個已固定的 28-record family 選一個有 code path context 的
record，將其 rendered glyph identity 與可查證的日文名稱／畫面語境交叉；若不能在
runtime listener blocker 下取得 context，改以 bounded caller literal／field
semantics 對照另一個 reader family，不把人工肉眼 OCR 升格為完整 source table。
