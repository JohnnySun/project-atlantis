## Evidence 分層

### Confirmed

- 三筆選定 ordinal 確實是各自既有 named prefix 的下一筆 address/stride record。
- 三筆 field 都是完整 16 bytes、固定最多 8 units、zero terminated；hash、count、
  termination 與 stable-ID candidate 可重抽取。
- 三筆 private identity match 全部 true；skill adjacent record 也能由多來源資料
  補上前一 cohort 未覆蓋的兩個字元 identity，沒有猜測或 OCR 反推。

### Provisional

- 這只確認三個 adjacent records，不代表 item/demon/skill 的整段 table 連續同類，
  也不表示相鄰 record 的 accessor 分支、runtime selection 或 scene category 相同。
- stable-ID candidate 可作為 bounded source-family key，但尚不是完整 translation
  ledger ID；仍須 source-table extent、control/width、回插與 runtime gate。

### Unknown / blocked

- main script、event、system source table，三個 family 的完整 extent 與中間 records。
- 未 anchor code-unit 的 Unicode/codepage、font replacement、自然 runtime writer
  arguments、翻譯 ledger、encoder、BPS 與 round-trip。

下一個最小切片應保持同一邊界：只再選明確可由外部資料核對的 sparse record 或
自然 caller source/index edge；遇到 category boundary、特殊 accessor 或無法多來源
核對時，記錄 negative 並停止擴張。
