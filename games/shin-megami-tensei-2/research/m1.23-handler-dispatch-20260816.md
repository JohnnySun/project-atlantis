# M1.23：encoded-string handler 的 bounded indirect dispatch

本切片只追 M1.22 已命名的兩個 state handler，以及其既有 static producer
reference；沒有再做全 ROM glyph／command 掃描，也沒有重跑同一個 reset→Start
runtime window。

## Scope and method

`tools/m123_handler_dispatch.py` 固定檢查兩個 ROM command stream 起點、兩個
producer callsite、callback table 的 entry 10/11、`0x0815cccc` trampoline，及
兩個 handler 的 bounded function boundary。每個 stream 只 hash 預先界定的 window，
並以已知 Thumb handler pointer 的前置 opcode 驗證 command boundary；argument 只
輸出 hash/count，不輸出 command word、argument value、source bytes 或字串。

可重現命令：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m123_handler_dispatch.py \
  --rom /path/to/A5TJ.gba \
  --output /private/tmp/smt2-m123-handler-dispatch.json
```

## Confirmed static chain

| edge | bounded evidence | result |
| --- | --- | --- |
| `0x080ced00` → queue producer | `0x080ced04` loads stream `0x084f0ec0`; `0x080ced06` loads `0xffff`; `0x080ced08` branches to `0x080ad0fc` | confirmed |
| stream A → handler A | 14 個 target command；前置 opcode 全為 `0x0b`；每筆 record 長 3 words、含 1 個 argument word | confirmed static indirect route |
| callback entry 11 | table stride `0x08`；first pointer `0x080ad3a9`；handler body `0x080ad3a8` 以 `0x0815cccc` (`bx r3`) dispatch | confirmed |
| handler A | `0x080ce760` boundary `0x080ceac0`；M1.22 已確認 state field `+0x1e` 與 4 條 family route | confirmed handler-to-family edge |
| `0x080d44a0` → queue producer | `0x080d44a8` loads stream `0x084f1514`；`0x080d44aa` loads `0xffff`；`0x080d44ac` branches to `0x080ad0fc` | confirmed |
| stream B → handler B | 1 個 target command；前置 opcode 為 `0x0a`；record 長 2 words、沒有顯式 argument word | confirmed static indirect route |
| callback entry 10 | table stride `0x08`；first pointer `0x080ad389`；handler body `0x080ad388` 以 `0x0815cccc` (`bx r3`) dispatch | confirmed |
| handler B | `0x080cf414` boundary `0x080cf4d2`；M1.22 已確認 state field `+0x1e` 與 5 條 family route | confirmed handler-to-family edge |

queue callback 的 register contract 也可由 bounded consumer 反組譯交叉：producer
entry `+0x14` 是 command-stream pointer、`+0x10` 是 stream index；callback 11
保持 `r0=queue entry` 並把一個 small-immediate selector 放在 `r1`，callback 10
沒有顯式 argument word。A 的 14 筆 command argument 只有 11 個 distinct small
selector class、domain 連續；工具不輸出每個 selector 值。這是 handler input
contract，不是 ROM source pointer、stable string ID 或 code-unit。

`0x080ced00` 的 direct BL callers 是 `0x08155e04` 與 `0x08157ea6`；兩者是
producer caller boundary，不能直接命名成劇情、惡魔、技能或道具類別。兩個
handler 本身的 direct BL caller count 都是 0；本切片因此確認的是「ROM command
stream → callback entry → indirect handler → M1.22 family route」靜態路徑，不是
runtime natural hit。

## Evidence layers

Confirmed：producer 的 ROM literal、queue BL、callback table entry、callback
handler boundary、trampoline target、bounded command count/opcode/length、queue
entry source/index field contract、small-selector argument class，以及 handler 到
M1.22 `0x0815bed4` family 的 static continuity。

Provisional：兩個 stream 是同一個 state/resource transition class；producer caller
是自然 category boundary candidate。這些命名不能取代 scene/state 或 runtime
frequency evidence。

Unknown：command argument 的語意、handler state 的自然來源、scene/category 名稱、
codepage、Unicode identity、字寬、控制碼與回插契約。listener 在本機仍有 attach 前
socket failure；本切片不把它寫成遊戲陰性，也不把 static route 寫成自然 runtime
命中。

因此 source table、stable string ID、translation ledger 與翻譯仍 blocked。下一個
最小缺口是沿 queue callback 呼叫約定，bounded 追 `r0` state object 與 handler
`+0x1e` writer/initializer 的 ROM／RAM provenance，直到取得可重抽取的 source/index
或 code-unit edge；若只能停在 command/resource class，立即轉回尚未命名的 text
reader family，不再增加 graphics 分類數量。
