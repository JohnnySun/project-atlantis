# M1.10 ROM pointer-table shape 與 bounded consumer（2026-08-16）

## 範圍

本回合只追 M1.9 caller provenance 指向的 `0x08198a98` 與 `0x087df54c`。
工作是 bounded ROM word/pair shape、literal reader、consumer callsite 與少量
target-window metadata；沒有重跑同一 reset→Start、沒有寫 RAM/selector、沒有
glyph scan、沒有輸出 table key、raw bytes、圖片、完整日文或 source table。

- ROM：`DDS_2`／`A5TJ`，8 MiB。
- SHA-256：`819a6a19a40bfbe7608f4b813dc18285c827f64e1523561ffe8e10ce8ab5991e`。
- 工具：`tools/m110_rom_table_shape.py`。
- 重現命令：

  ```sh
  PYTHONDONTWRITEBYTECODE=1 python3 -B \
    games/shin-megami-tensei-2/tools/m110_rom_table_shape.py \
    --rom /private/tmp/smt2-a5tj.gba \
    --output /private/tmp/smt2-m110-static.json
  ```

報告 schema 為 `smt2.m1.10.rom-table-shape.v1`；JSON 只留在 `/private/tmp`。

## `0x08198a98`：variable word stream

bounded 0x400-byte window 的 SHA-256 為
`32e2fa9d7b71b21587db3663ca3cfae241820d07d6e2f6469964a46f4db27773`，共 256
words、17 個 ROM-pointer-shaped words、14 個 Thumb-shaped pointers；sentinel
`0x10241224` 出現在 offsets `0x5c` 與 `0xa4`。第一個 sentinel 前為 96 bytes，
pointer runs 是 `[3, 1, 1, 1, 1, 1, 1]`，因此本回合只命名為
`variable_word_stream_with_sentinels`，沒有推導固定 stride。

唯一 tracked literal reader 是：

- literal load `0x080bee30` → ROM address `0x08198a98`；所在 Thumb function
  `0x080bee24` 的 256-byte window hash 為
  `55e8e7c536985b7aa6ec67121fe81fa6478fd6f8d5c8f9b4eb5832c19457fb4d`。
- callsite `0x080bee40` 先以 IWRAM halfword
  `0x03004550 + 0x62` 作 `index * 4`，再取
  `word(0x08198a98 + index*4)`，送入 `0x0813e428`。這是 state/resource
  pointer consumer；不是已證明的文字表或 code-unit table。

## `0x087df54c`：fixed pair run

從 `0x087df54c` 開始的第一個連續 run 有 125 筆 `key + ROM data pointer`，
stride `0x8`、span `0x3e8` bytes；span SHA-256 為
`3adf2337939ad4779d72040dbe94f288b6e3abfb1cb9ded52a79b8b14c7becae`。pointer
欄位 125 筆全部 even、99 個 unique，且都落在 ROM region；offset `0x3e8` 是
第一個 non-ROM pointer break。這支持 `fixed_key_plus_rom_pointer_pairs`，但
不命名 key 語意或 target 資料格式。

唯一 tracked literal reader 是：

- literal load `0x08153466` → ROM address `0x087df54c`；所在 Thumb function
  `0x08153458` 的 256-byte window hash 為
  `1b8c19e6e0a7a8ba70fb7cb12d3aa75189024043577a3e762898479dd96e2532`。
- callsite `0x081534ae` 讀 record `+0x04` pointer，再送入
  `0x0813e428`。這是 bounded resource-pointer consumer，沒有自然 runtime hit
  或文字身份證據。

## Target-window 交叉與陰性

工具只對前八個 unique target 各讀 0x80 bytes，保留 address、hash、word count、
ROM-pointer count、Thumb-pointer count 與低位 LZ77-header count，不保存內容。
前八個 target address 為 `0x080732bc`、`0x0807349e`、`0x08064cfe`、
`0x08073684`、`0x080680cc`、`0x0804d26c`、`0x0804d2ba`、`0x0804d356`；
這八個 bounded window 的 LZ77-header count 都是 0。這只是窄窗口陰性，不能
推論 target 全區未壓縮，也沒有把 resource bytes 當翻譯來源。

兩個 tracked table 都是 ROM-resident：本回合沒有找到 RAM writer；讀出的下一個
consumer 仍是 selector state/resource swap。`0x08198a98` 的 variable stream、
`0x087df54c` 的 pair table 與 target windows 都沒有建立 source pointer→
code-unit→glyph writer 的因果鏈。

## 分類與下一個缺口

### Confirmed static

- `0x08198a98` 的 bounded variable/sentinel shape、reader `0x080bee30`、
  index source 與 `0x080bee40 → 0x0813e428` edge。
- `0x087df54c` 的 125×8 pair run、ROM pointer span、reader `0x08153466` 與
  `0x081534ae → 0x0813e428` edge。

### Provisional

- 兩個 ROM table 的實際用途仍可能是 resource/state dispatch；pointer target
  尚未做完整 data decoder，不能命名為惡魔、技能、道具、劇情或文字資料。
- 前八個 0x80-byte target-window LZ77 negative 只限該窗口，不是全 target
  format 證明。

### Negative / blocked

- M1.8 的三組 natural selector negative 與 M1.9 的 static-only 限制保持；
  本回合沒有 synthetic selector/state write，也沒有新的自然 runtime 宣稱。
- glyph source chain、codepage、stable string ID、控制碼、source table、
  翻譯 ledger、可靠回插與 BPS 仍封鎖。

下一個最小缺口是沿兩個 reader 的實際 data target 做 bounded source-class／
consumer mapping；若仍只得到 resource/state records，應轉向下一個可命名文字
consumer，而不是把這兩張 table 當成翻譯來源。
