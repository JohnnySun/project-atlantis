# M1.18：16-bit code-unit、font bank 與 bounded source pointer table

## Scope

本切片只追一條已命名的 code-unit consumer，不重做 M1.15 的 resource
classification、不掃描全 ROM glyph pattern，也不輸出原始字串、字模、圖片或
翻譯 ledger。可重現入口是：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m118_codeunit_font.py \
  --rom /path/to/A5TJ.gba \
  --output /private/tmp/smt2-m118-codeunit-font.json
```

## Confirmed static chain

```
16-bit source pointer
  -> 0x080ac3ac / 0x080ac334
  -> ldrh, +2 bytes per code unit
  -> 0x0300 line-break branch; 0x0301 terminator
  -> 0x080ac2a0 / 0x080ac218 renderer
  -> 0x020360dc dynamic code-unit map
  -> cache miss: 0x080abf24
  -> 0x0815ed88 bank-pointer table
  -> 0x020391e0 / 0x020395e0 bounded font scratch
  -> descriptor 0x0815ee18
  -> OAM record writer family
```

The bank addressing is verified from the Thumb operations and literal loads:
the high byte of a 16-bit unit selects an entry with stride `0x08`; the low
byte contributes `((low >> 4) << 10) + ((low & 0x0f) << 5)` to the selected
font bank. This is an addressing rule, not a Unicode identification.

## Bounded source candidate

The direct callsite `0x080dd884` loads a pointer from
`0x085861c8 + signed_object_field_0x02 * 0x08 + 0x04` and calls
`0x080ac3ac`. The audited bounded prefix has 28 records, stride `0x08`, IDs
1 through 28, and ROM pointers that each terminate with `0x0301` within the
next-pointer window. Each record is represented only by address, ID, length,
hash, termination class, unit counts, and `0x0300`/`0x0301` counts in the
probe report.

This is the first bounded Japanese encoded-string source candidate. Its
category semantics are still provisional: the caller is a state/UI path and
the repository does not yet have a runtime scene-to-record proof. It must not
be treated as the complete main script or translated without that mapping.

## Evidence status

- **Confirmed:** 16-bit unit width, +2 reader advance, `0x0300` line break,
  `0x0301` terminator, font bank pointer table, two EWRAM scratch destinations,
  descriptor edge, and the 28-record pointer-table shape.
- **Provisional:** the bounded table is a Japanese name/UI category and its
  records can serve as stable IDs for a later category-specific extractor.
- **Unknown:** category name, Unicode mapping, complete story/event banks,
  control codes beyond the two observed units, glyph identity, translated
  width rules, and reversible reinsertion.

The translation ledger remains blocked. No source bytes or decoded Japanese
text are committed.
