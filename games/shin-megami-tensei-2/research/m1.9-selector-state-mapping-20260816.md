# M1.9 selector state argument mapping（2026-08-16）

## 範圍與可重現輸入

本回合只承接 M1.8 已列出的四個 `0x03006950` writer candidate，做 bounded
Thumb literal/store 解碼、literal pool 交叉、direct BL caller 與最多三層
caller mapping。沒有重跑 reset→Start、沒有寫 selector/state、沒有做全 ROM
glyph pattern scan，也沒有輸出 instruction bytes、RAM/ROM payload、圖片或完整
日文。

- ROM：`DDS_2`／`A5TJ`，8 MiB。
- SHA-256：`819a6a19a40bfbe7608f4b813dc18285c827f64e1523561ffe8e10ce8ab5991e`。
- 工具：`tools/m19_state_mapping.py`。
- 重現命令：

  ```sh
  PYTHONDONTWRITEBYTECODE=1 python3 -B \
    games/shin-megami-tensei-2/tools/m19_state_mapping.py \
    --rom /private/tmp/smt2-a5tj.gba \
    --output /private/tmp/smt2-m19-static.json
  ```

報告 schema 為 `smt2.m1.9.static-state-mapping.v1`；完整 JSON 只留在
`/private/tmp`，不進 Git。

## Thumb boundary 與 writer edge

四個 seed 都以 `push {…,lr}`（`0xb5f0`）開頭。工具以第一個 bounded high-register
`BX` epilogue 作函式區間交叉點，並另外保留後續 bounded return candidates；這
是 ARM7TDMI/Thumb 的可重跑邊界檢查，不把 literal pool 當指令。

| seed | 256-byte window SHA-256 | first epilogue candidate | direct BL callers |
| --- | --- | --- | ---: |
| `0x0812f2b4` | `91246ccd3032bb4d447d9531edf944c74d251c4ace328ab102bbf04f6357437f` | `0x0812f520` | 5 |
| `0x0813e184` | `a667f62e9d31ec2600c80ea4b26bf237c0f782b9e8ab929733de78d79bf3ba64` | `0x0813e32c` | 4 |
| `0x0813e428` | `e777aef8c6ee505b37af870cf703304eed3bb61dedce3c10203616becddd8883` | `0x0813e53c` | 7 |
| `0x0813e574` | `c91a3dab3c91b31d52eea34bac91599544002d85e2265a5ebe3d0c2e94a190c4` | `0x0813e5da` | 3 |

確認到的 static edges：

- `0x0812f2b4 → 0x0812f386 → 0x03006950`：source `r0` 是 literal
  `0x08036666`（ROM pointer）。同一函式另有 `0x08036156`、`0x0803631e`
  的 ROM literal branch，以及 runtime/stack-derived branch；因此不能把這個
  單一路徑命名成 reset initializer。
- `0x0813e184 → 0x0813e22a → 0x03006950`：source `r6` 可由 linear
  provenance 還原為函式 incoming `r0`；這是 caller supplied state pointer，
  不是固定文字表。
- `0x0813e428 → 0x0813e44e → 0x030068c0`：source 是
  `[0x03006950]`，保存當前 selector pointer。
- `0x0813e428 → 0x0813e458 → 0x03006950`：source 是函式 incoming `r0`，
  表示 selector swap 的輸入參數。
- `0x0813e574 → 0x0813e5b2 → 0x03006950`：source 是
  `[0x030068c0]`，確認 RAM save/restore edge。該函式同時有 bounded
  `0x030066b0 → 0x03005ca8`、length `0x167` 的 byte-copy loop
  （loop `0x0813e59a`、16-byte hash
  `5e571cfa1b78d36a4f048cde132e33aefc65672627544b25f6666380ced16904`）
  也已由工具輸出 metadata；這不是 OBJ glyph staging，沒有把它升格為文字來源。

## Caller 1–3 層與參數 provenance

工具對四個 seed 共保留 5、36、87、68 筆 bounded caller records（分別以
seed depth 1–3 展開）；每筆只含 callsite、caller function hash/length、Thumb
boundary flag、context form/count 與 r0–r3 provenance。最接近 source/index 的
第一層紀錄如下：

- `0x080bee40`／`0x080bee4e` → `0x0813e428`：`r0` 是由 runtime halfword
  `0x03004550 + 0x62` 計算索引，再從 ROM table literal `0x08198a98` 取 word。
  這是 ROM-table-derived pointer 的 provisional edge，不是文字 source。
- `0x081534ae` → `0x0813e428`：`r0` 來自 ROM literal `0x087df54c` 的
  `+0x04` word。這是另一個 ROM-table-derived pointer 的 provisional edge。
- `0x080c309a` → `0x0813e428`：wrapper 直接轉送 incoming `r0`，source
  provenance 仍在更上層。
- `0x080c4848` → `0x0813e428`：`r0` 是 subroutine return 後的 runtime
  load，尚未能命名 source table。
- `0x0813e4cc`／`0x0813e51c`／`0x0813e52e` → `0x0813e574`：同一
  `0x0813e428` 內的 branch/callback helper，證明 restore helper 的呼叫
  關係，但不是自然 selector transition。

`0x0813e428` 的 caller graph 已向上展開三層；其中 boundary 無法穩定命名的
callsite（例如 `0x080b11e2`）保留為 unknown，不用 nearest prologue 猜成已確認
函式。`r0–r3` 的 mapping 是線性 static inference，遇到 branch/return 仍標為
provisional；它不是 live RAM 值，也不替代 runtime watchpoint。

## 狀態分類與缺口

### Confirmed static

- `0x0813e428` 是 selector pointer swap：保存 `[0x03006950]` 到
  `0x030068c0`，再以 incoming `r0` 寫回 `0x03006950`。
- `0x0813e574` 由 `[0x030068c0]` 還原 selector pointer。
- `0x0812f2b4` 至少有一條明確 ROM literal→selector store edge，literal
  位置與函式 boundary 可重現。

### Provisional

- `0x08198a98`、`0x087df54c` 是 caller argument 所經過的 ROM table/word
  provenance；尚未證明其 record stride、source writer、用途或與文字的關係。
- `0x030066b0 → 0x03005ca8` 是 bounded RAM copy；尚未證明是字型、文字或
  OBJ staging。
- 三層 caller provenance 可能受 branch merge 影響，必須以自然 runtime hit
  或下一個精確 consumer 交叉。

### Negative / blocked

- M1.8 的 `boot-start`、`fast-start`、`aggressive-start` 及 initializer-only
  follow-up 仍是自然 selector-table write/read、selector caller、descriptor
  producer/callback 的 bounded negative；本回合沒有把 static edge 升格成自然 hit。
- 尚未取得 source pointer→code-unit→glyph writer→OBJ VRAM→OAM 因果鏈，沒有
  codepage、stable string ID、控制碼、source table、翻譯 ledger 或回插格式。

下一個最小缺口是 bounded 解析 `0x08198a98`／`0x087df54c` 的 table shape 與
其 source writer；若仍只得到 state/resource pointer，應記錄精確陰性並轉向文字
consumer 的下一個可命名 code-unit edge，不再擴大同一 reset→Start runtime window。
