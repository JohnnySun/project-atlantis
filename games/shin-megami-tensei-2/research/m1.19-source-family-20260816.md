# M1.19：reader family 與 bounded inline source family

## 範圍

本回合只沿 M1.18 已命名的 `0x080ac334`（small）與 `0x080ac3ac`
（large）兩個 16-bit reader 做 direct-caller／caller-layer mapping。沒有重做
M1.15 的 resource decoder、OBJ 比對或全 ROM string/glyph scan；工具只輸出地址、
function boundary/hash、pointer、length、termination、unit class/count 與 hash。

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m119_source_family.py \
  --rom /path/to/A5TJ.gba \
  --output /private/tmp/smt2-m119-source-family.json
```

## Confirmed static evidence

- small reader 的 direct BL index 在 64-callsite bounded cap 內得到 64 筆；large
  reader 得到 5 筆。每筆保留 caller boundary、window hash 與最多三層 direct BL
  caller edge；不得把這個 bounded index 稱成全 ROM caller 完整清單。
- large reader 的既有 M1.18 source path 維持分層：`0x080dd884` 是
  `0x085861c8` record pointer load 後的 ROM-table-derived path；`0x080e0b72`、
  `0x080e115a`、`0x080e14fc`、`0x080e17a6` 是先形成 `sp+0x0c` 16-bit stack
  buffer 再消費的 paths。M1.19 工具對呼叫前簡單 r0 setup 只做 linear-bounded
  candidate 記錄，不把它升格為完整 CFG/data-flow proof。
- `0x080b52c4` 內的 bounded literal refs 形成 15 個有序 ROM pointer：base
  `0x08162b0c`、最後 `0x08162c26`。每筆以 `0x0000` 結束，15/15 termination
  confirmed；pointer delta、consumed length、unit class、hash 與同一 caller
  function boundary 都可重抽取。這是與 M1.18 `0x085861c8`／`0x0301` family
  分開的 inline zero-terminated candidate。
- family 的 15 筆 record ID 是 bounded pointer-order IDs 1–15，僅代表可重抽取
  addressing，不代表角色、地名、惡魔、技能、道具或劇情語意。

## Evidence status

- **Confirmed:** two reader entries and bounded direct callers; 3-layer caller
  metadata; `0x080b52c4` inline pointer set; 15/15 zero termination; no raw source
  or decoded text emitted.
- **Provisional:** inline family 可能是 UI/system code-unit category；caller
  argument classification outside the exact M1.18 table path is linear-bounded。
- **Unknown:** natural scene selection、category semantics、Unicode/codepage、
  main/event/demon/skill/item family boundaries、control codes beyond `0x0000` and
  `0x0301`、width budget、reinsert contract。

Runtime natural transition evidence is not claimed here. The previously recorded
headless mGBA GDB listener socket failure remains an environment boundary; no
selector/table/state write or synthetic transition was used to fill that gap。

The translation ledger remains blocked. The next minimum slice is to identify one
reader caller's live/object state-to-pointer selection and distinguish this inline
family from the main/event/demon/skill/item data families, while retaining the same
metadata-only source/work separation.
