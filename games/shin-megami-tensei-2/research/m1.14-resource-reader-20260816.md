# M1.14 descriptor reader → staging writer（2026-08-16）

## 範圍與重現

本回合只追 M1.13 已命名的 descriptor base、state dispatch、queue opcode
reader 與 `0x0813ef65` callback。沒有再做全 ROM glyph scan，也沒有輸出
descriptor bytes、source payload、raw tile、圖片、完整日文或翻譯 source table。

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m114_resource_reader.py \
  --rom /private/tmp/smt2-a5tj.gba \
  --output /private/tmp/smt2-m114-static.json
```

工具輸出 address、PC／callsite、function boundary、length、hash、region、
bounded source-window hash、argument count 與 dispatch metadata。ROM identity
仍以 `research/recon-20260816.md` 為準。

## Confirmed static chain

1. `0x0813ef40` 是 28-byte Thumb state-dispatch wrapper，透過 literal
   `0x0203b554` 的 halfword index，從 `0x0879243c` 的 8-entry、stride `4`
   table 取 handler，再經 `0x0815ccc0` 的 `BX r0` tail dispatch。table index
   `5` 位於 `0x08792450`，值為 Thumb pointer `0x0813f22d`，對應
   `0x0813f22c`。
2. `0x0813f22c` 是同一 handler 的長 state function；prologue 與第一個
   `BX` boundary 為 `0x0813f22c`–`0x08140102`（length `0xed6`），bounded
   window/full-span hash 已由工具保存。其 callsite `0x0813f242` 將 literal
   descriptor base `0x08794e24` 放入 `r0`，將 `0x0000ffff` 放入 `r1`，呼叫
   queue producer `0x080ad0fc`。這是 static conditional state path，不是
   natural runtime hit。
3. queue drain `0x080ad01c` 以 entry `+0x14` 作 stream source、`+0x10` 作
   word index，從 stream 取 opcode，再用既有 25×8 callback table
   `0x0815eeec` dispatch。descriptor base 的初始 word 是 opcode `0x0c`。
4. callback table entry `12` 位於 `0x0815ef4c`，值為 Thumb pointer
   `0x080ad3cd`；handler entry `0x080ad3cc` 的 boundary 是 34 bytes，第一個
   return 在 `0x080ad3ec`。它從 queue 的 current-cursor 讀取：

   - `r3`：callback pointer（record `+0x00`）；
   - `r1`：ROM source pointer（record `+0x04`）；
   - `r2`：bounded callback argument（record `+0x08`）；
   - 再經 `0x0815cccc` 的 `BX r3` 呼叫 callback。

5. 因此 `0x0813ef65` 的 128 次 exact pointer occurrence 不只是 shape match：
   每次前一個 word 都是 opcode `0x0c`，而其 `+0x04` 欄位均為 ROM pointer。
   bounded stream 中可重複辨識出 16 組、每組 8 次 callback、stride `0x18`；
   `r2` argument 的 `0..7` 各出現 16 次，128 個 source pointer 均 unique 且
   位於 ROM。source window 只以 hash／length 保存；各 source 的 low-byte
   marker 都是 `0x24`。M1.14 仍保守不命名格式；M1.15 的 bounded decoder
   已確認它是 GBA 4-bit Huffman header，且每筆 Huff output 都銜接有效
   `0x10` LZ77 stream。
6. callback `0x0813ef65` 進入 M1.13 已確認的 34-byte writer `0x0813ef64`。
   writer 的 incoming `r1` 進入 SWI `0x13` Huff wrapper `0x0815cafc`，中間
   目的地是 `0x0200afc8`；incoming `r2 << 12` 加上 `0x02001000`，再進入
   SWI `0x11` LZ77-WRAM wrapper `0x0815cb00`。因此這一回合已建立
   **ROM source pointer + bounded argument → callback → decompression →
   staging-bank expression** 的 static 因果鏈。

## 1–3 個 bounded source links

第一組 callback 的前三筆由工具分別記為：

| stream record | source pointer | callback argument `r2` | staging expression |
|---|---|---:|---|
| `0x08794e28` | `0x087a07dc` | `0` | `0x02001000` |
| `0x08794e40` | `0x087a0d04` | `1` | `0x02002000` |
| `0x08794e58` | `0x087a1168` | `2` | `0x02003000` |

這些是 address／argument／hash 的 addressing evidence；沒有畫面位置、已知
Unicode identity 或 source code-unit，因此三筆都不能命名為特定 glyph。對
`r2=0` 的 `0x02001000 → 0x06010000` consumer edge 可與 M1.12 的 static
DMA evidence 對接，但尚未有自然 runtime event 證明這三筆在 Start 免責畫面
中被選取。

## 分層結論

### Confirmed

- state-table index `5` → Thumb handler `0x0813f22d`；
- handler → descriptor base `0x08794e24`／queue producer；
- opcode `0x0c` → callback-table entry 12 → `0x080ad3cd`；
- callback record source `+0x04`／argument `+0x08` → `0x0813ef65` writer；
- writer 的 Huff→LZ77 staging expression與前三筆 bounded source links。

### Provisional

- 16×8 callback runs 是 resource/asset command stream 的 bounded candidates，
  M1.15 已確認其 source payload 是 Huff→LZ77 的固定 4 KiB 4bpp asset class，
  不是文字表；相鄰 word 仍由 opcode stream 消費，不能把整個 `0x18` span
  當固定文字 record。
- `r2` 是 output bank/index candidate，不是 code-unit；M1.15 的格式解碼仍
  沒有給出 code-unit、string ID 或 Unicode identity。

### Unknown／negative

- 尚未取得 code-unit、string ID、Unicode identity、控制碼、字寬或實際畫面
  glyph link；因此 codepage、source table、翻譯 ledger 與回插仍封鎖。
- M1.12/M1.13 的 bounded runtime probe 在 GDB attach 前受到本機 mGBA
  listener socket／port blocker；本回合不把 static chain 當自然 runtime hit，
  也不把 listener blocker 當遊戲 negative。
- 下一個最小缺口是：在 listener 可用時，對 state global／queue entry、
  `0x080ad3cc`、`0x0813ef64` 與 staging/DMA edge 做單一路徑 runtime capture，
  取得實際 PC/LR、r1/r2、source/staging hash；若仍無文字 identity，轉向
  `0x087a*` source class 的 bounded decoder，而不建立翻譯 ledger。
