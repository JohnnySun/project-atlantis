# M1.22：`0x0815bed4` family 的 state-field route

## Scope

本切片只分析 M1.21 指出的兩個 caller：`0x080ce760` 與 `0x080cf414`。工具
驗證 state halfword load、literal pointer route、named reader callsite 與同一個
bounded pointer family 的 termination/hash metadata；不做 runtime state write、
全 ROM scan 或文字解碼。

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -B \
  games/shin-megami-tensei-2/tools/m122_state_routes.py \
  --rom /path/to/A5TJ.gba \
  --output /private/tmp/smt2-m122-state-routes.json
```

## Confirmed static chain

- `0x080ce760` 在 `r6 + 0x1e` 讀取 halfword state，四條 bounded literal route
  分別到 `0x0815bf4a`、`0x0815bf0e`、`0x0815bf62`、`0x0815bf7c`；其五個
  named reader callsite 全部 target `0x080ac334`。
- `0x080cf414` 在 `r2 + 0x1e` 讀取 halfword state，五條 bounded literal route
  分別到 `0x0815c02c`、`0x0815c048`、`0x0815c05a`、`0x0815c06e`、
  `0x0815c082`；其兩個 named reader callsite 全部 target `0x080ac334`。
- 兩組合計 15 個 pointer，從 `0x0815bed4` 到 `0x0815c082`；bounded probe
  15/15 都以 `0x0301` 結束。這證明 state-field→consumer-compatible pointer
  route，不證明內容是主劇情、惡魔、技能、道具或系統文字。

## Evidence status

- **Confirmed:** ARM7TDMI Thumb halfword field offset `0x1e`、兩個 function
  boundaries、4+5 literal routes、reader targets 與 15/15 termination metadata。
- **Provisional:** 這 15 筆是同一個 encoded-string category boundary；state values
  是 UI/system mode 的推測標籤，尚未有自然 scene proof。
- **Unknown:** route 的實際自然觸發場景、Unicode/codepage、category semantics、
  main/event/demon/skill/item relationship、width 與 reinsertion。

Translation ledger remains blocked. Existing mGBA GDB listener socket failure is
kept separate; no selector/table/state was written and no synthetic route was used。
