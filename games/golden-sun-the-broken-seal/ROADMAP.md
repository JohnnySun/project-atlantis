# 工作路线

## 1. 建立可重复构建

- [x] 保存日版原 ROM、上游 BPS 和公开测试版构建。
- [x] 记录基准校验值。
- [x] 保存旧汉化版参考样本与本地备份。
- [ ] 增加一键构建、打包、校验脚本。
- [ ] 增加构建产物清单与自动校验脚本。

## 2. 逆向文本系统

- [x] 比较日版与 2024 新汉化版的 ROM 布局。
- [x] 定位日版 Huffman 文本、新版直接字符串表及字体渲染钩子。
- [ ] 比较旧汉化版的 ROM 布局与文本系统。
- [ ] 完成自定义中文码页与字库映射。
- [ ] 编写无损文本提取器和回插器。
- [ ] 对未修改文本执行提取后回插，验证 ROM 行为一致。

## 3. 文本修订

- [ ] 建立人物、地点、精神力、精灵、道具和怪物术语表。
- [ ] 建立问题单：场景、原文、现译、建议、截图和状态。
- [ ] 先处理错字、标点、溢出和明显误译。
- [ ] 再处理语气、语域与全局术语统一。
- [ ] 若制作繁体版，先审计字库覆盖率和界面宽度，避免机械简繁转换。

## 4. 程序与兼容性

- [ ] 收集可稳定复现的异常，不根据模糊描述猜测补丁地址。
- [ ] 在 mGBA 与至少一个独立的模拟器或 GBA 相容环境中分别验证。
- [ ] 区分游戏缺陷、汉化缺陷、模拟器缺陷和存档版本问题。

## 5. 发布

- [ ] 以校验正确的日版原 ROM 为基准生成新的 BPS。
- [ ] 发布补丁、变更记录、校验值和已知问题，不发布商业 ROM。
- [ ] 保留上一稳定构建，实验版通过验证后才标记为可发布版本。
