# 路線圖

## 里程碑 1：可逆試補丁

- 完成日版字形 ID 到 Unicode 的映射。
- 確認對話控制碼、換行、姓名插值及字寬規則。
- 從已納入的開源 CJK 字庫生成最小簡體／繁體子集。
- 把少量開場文字寫入擴展區，接入新的字串與字形查找路徑。
- 從指定雜湊的乾淨日版 ROM 生成 BPS，並驗證套用後雜湊。
- 在 mGBA 跑通開機、標題、開場對話、選單與存檔。

## 里程碑 2：可審核翻譯資料

- 將日版原文映射成 Unicode，按字串 ID 匯出本地工作集。
- 以英文公開腳本或其他可合法使用的材料作語義參考，但以日文原案為準。
- 建立人名、地名、精靈、精神力、道具和戰鬥用語的簡繁術語表。
- 逐條保存譯文來源、審核狀態、寬度預算及控制碼完整性。

## 里程碑 3：完整構建與 QA

- 重建全部文字資料和字庫。
- 自動檢查漏譯、控制碼、缺字、超寬行及術語不一致。
- 覆蓋主線、支線、戰鬥、商店、精靈、轉移存檔和通關後內容。
- 分別發布簡體與繁體 BPS；不發布 ROM。
