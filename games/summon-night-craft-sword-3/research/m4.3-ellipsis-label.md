# M4.3：resource-25 ellipsis label

這是第四筆 cumulative static `ai_draft` target。它選用 resource 25 的一筆
opaque-free、8-byte／4-code-unit、單行語氣標籤；沒有專有名詞。日文 source 只由
ignored 361-row table 讀取，本文件只保存 hash、stable ID、結構與 target-side
evidence。

## Ledger／translation contract

- `string_id`：`b3cj:t2:025:0x0b6e`
- source hash：`edfe7b0a4cfae39281960bcfeb2592b66bbd47136d6b29c1bc2082dc5cf8e2c9`
- target locale：`zh-TW`；target：`嗯…　　`；status：`ai_draft`
- target 是四個 code unit、8 bytes、單行；兩個全形空白是明確 text units，
  用來保留 record 長度，不把 `0x0000` terminator 當 padding。
- record controls 保留 `0x0308`／`0x0000`，following corpus opcode 只有
  `0x0308`，opaque control count 為零。
- ledger 由 `prepare → core restore → core strip` 產生；tracked ledger 只有
  source hash、target、context 與 review metadata，沒有 source text。

## Glyph／static insertion

target code units 固定為 `ec6d 8163 8140 8140`。`8163`（ellipsis）與 `8140`
（全形空白）沿用 clean mapping；`ec6d` 在 clean ROM 是 table value `0x0000`
的 opaque extension，配置到下一個允許的 blank slot `0x84c`。Unifont 17.0.05
產生的 cell SHA-256 是
`3cad75fe84f620f11808603a1829eff157ec27d6b9de842d69c3d8ad55bc3cc6`；沒有使用
fallback、out-of-resource target 或重複 slot。resource 25 相鄰 record
`0x0b7a` 與 adjacent glyph `0x0ac` 仍 byte/render identical。

## Cumulative build／round-trip

`tools/build_m4_3_batch.py` 從 clean B3CJ ROM 依序重建 M2.5、M4.1、M4.2，加入
`ec6d` font table/cell，再替換 resource 25 record。它只在原 resource span 內
寫入 LZ77 output，並以全部 361 筆 source rows 做 cumulative re-extraction：target
`4`、untouched `357`。

  `0071b4b21ea6c3f423d55c427b99d5e5c561377c46331a592387423a75985fe3`
- target ROM CRC32：`7b578dad`

  `a1dddaf7e763e5681c60fc20bf99614056c304ee30b94260d76296170a6197d8`

ROM、BPS、working ledger、source adapter 與 summary 都留在 ignored `work/`；
tracked 只提交 `translations/m4.3-ellipsis-label.jsonl` 與工具／研究摘要。

這是 static ledger、glyph cell、record／resource re-extraction 與 BPS evidence，
