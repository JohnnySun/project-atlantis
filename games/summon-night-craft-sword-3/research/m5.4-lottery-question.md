## Codepage／font proof

target code units：`9776 928a ec65 ec6f 8148 8140 8140`。

- `要` (`9776`)、`抽` (`928a`)、`？` (`8148`) 與全形空白 (`8140`) 使用現有 mapped glyph。
- `獎` 沿用 M2.5 的 `ec65→0x848`。
- 唯一新配置是 opaque extension `ec6f→0x84e` 的 `嗎`；slot 位於 fail-closed
  `0x845..0x85f`，clean table value 是 `0x0000`、cell 為全零，Unifont cell SHA-256
  為 `10735ef11520f9aa72889a8da1b3443f131a2fc123a96c736b6423b113bf9b88`。

builder 以 M5.3 ROM 作為新增 glyph 前的 cumulative baseline，確認 `ec65`、
`9776`、`928a`、`8148`、`8140` 的 mapping／cell SHA-256 不變；destination zero-fill
guard 則在 clean ROM 上重跑，避免把已填入 compressed payload 的 cumulative destination
誤當成空白區。
