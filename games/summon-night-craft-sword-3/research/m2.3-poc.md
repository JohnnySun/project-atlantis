# B3CJ M2.3 glyph allocation／bounded encoder 收據

本切片把 M2.2 的靜態 glyph POC 收斂成固定 manifest 與 fail-closed encoder。
它只接受已驗證的 B3CJ clean ROM、M2.1 ignored source table、固定 GNU Unifont
source 與 tracked manifest；輸出 ROM、summary、PGM 與任何 raw data 都留在
ignored `work/`。這是格式／回插風險的 bounded proof，不是翻譯完成、可發布
patch 或完整 ROM builder。

## 固定輸入與 allocation contract

| 項目 | 固定值 |
| --- | --- |
| ROM | B3CJ、CRC32 `12afae5d`、SHA-256 `39bc4cf448106aa4b8cdde235632ffb57432c4b1919c8843510b70b3787fad2d` |
| source table | 361 records；ignored JSONL SHA-256 `a050790267679a35b1300f8ed3056271b6c481124790e9249484ce9d1d7966e3` |
| font source | GNU Unifont `17.0.05`；SHA-256 `2ae5311c8e123e9e85f5331cd012aa99757071df23243f1487fdbf8f3acd86be` |
| font resource | type `3`／id `2`，glyph base file `0x14d5c88`，cell／stride `0x18` |
| allocation range | 僅 `0x845..0x85f`，共 27 slots |
| manifest | [`m2.3-glyph-manifest.json`](m2.3-glyph-manifest.json)；SHA-256 `22d9d27aa62070bfcc403edc3730d73a6d68a9da87cd97f78c4d45ae653f7e3e` |

manifest 保留既有 mapping，只准兩個明確 `opaque_extension` code unit：
`ec48`→Unicode `的`／slot `0x845` 與 `ec49`→Unicode `你`／slot `0x846`。
這兩個 Unicode identity 只用來選固定 glyph source；raw code unit 並非宣稱為
日文 Shift-JIS，也不代表已審核翻譯。

encoder 在讀取 ROM 前就拒絕錯誤 revision、ROM／source／font hash、非 opaque
extension、strict Shift-JIS collision、重複 code unit、重複 slot、slot 範圍外、
record 數量超限、未分配 target、target byte length 不符與容量超限。對既有
codepage target，`fallback` 與 out-of-resource 都不算 mapped target；只有新的
opaque allocation 在 clean ROM 上可用 `table_value=0` 作為「尚未佔用的 table
entry」前置條件，patch 後必須重抽為 mapped。這個名稱區分避免把安全空槽誤當
成可接受的 fallback glyph。

## bounded POC 結果

執行：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 games/summon-night-craft-sword-3/tools/encode_m2_3_poc.py \
  games/summon-night-craft-sword-3/roms/base/B3CJ-jp-from-zip.gba \
  --source-jsonl games/summon-night-craft-sword-3/research/summon-night-craft-sword-3-decoded.jsonl \
  --manifest games/summon-night-craft-sword-3/research/m2.3-glyph-manifest.json \
  --font-source vendor/fonts/unifont/unifont-17.0.05.hex.gz \
  --output games/summon-night-craft-sword-3/work/m2.3-poc.gba \
  --summary-output games/summon-night-craft-sword-3/work/m2.3-poc-summary.json \
  --render-output games/summon-night-craft-sword-3/work/m2.3-poc.pgm
```

| 項目 | 收據 |
| --- | --- |
| allocation | `ec48`／`ec49` → `0x845`／`0x846`；adjacent untouched glyph `0x844` |
| records | `b3cj:t2:022:0x011a` target `ec48 ec49`（4 bytes）；`b3cj:t2:025:0x1270` target `ec49`（2 bytes） |
| source contract | 兩筆 source raw／record hash 由 manifest 固定；實際 source text 只從 ignored JSONL 讀取，不寫入 tracked output |
| resource 22 | decoded `1094` bytes；compressed `485` → `485`，original span `496` |
| resource 25 | decoded `5148` bytes；compressed `1652` → `1652`，original span `1664` |
| patched ROM | SHA-256 `ce99a443cfab8f84cc7f7a0319b9271ce3173dc64c488ca138696ae938460a07`（ignored） |
| static render | 3 cells，PGM SHA-256 `dd9fa9b7c972e29d2950682fe9613867aefe2dc444686bca930343df86f901d4`（ignored） |
| byte diff | `1753` changed bytes；所有差異均在兩個明確 font table/cell 區域或兩個原 resource span，無 manifest 外差異 |
| round-trip | font mapping／cell、record、PSI3 stream 均 `byte_identical`；LZ77 只證實在原 resource span 內可重建，不宣稱 pointer table／header／完整 ROM checksum 已完成 |

`tools/encode_m2_3_poc.py` 先在記憶體完成所有驗證，再一次寫入明確 ignored
輸出路徑；不會覆寫 clean ROM。`tools/test_encode_m2_3_poc.py` 覆蓋實際 POC、
固定 hash、slot／code-unit duplicate、strict collision、fallback／out-of-resource
狀態與 resource capacity overrun。

## runtime QA 收據

本輪只做一次高位 port 嘗試，沒有重寫 port shim：

1. `24387` bind preflight 回報 `PORT_24387_FREE`。
2. 啟動命令為 `/opt/homebrew/bin/mgba -g -C ports.qt.gdbPort=24387 games/summon-night-craft-sword-3/work/m2.3-poc.gba`，程序 PID `26484`。
3. `lsof -nP -a -p 26484 -iTCP` 證實 mGBA 實際只 listen `*:2345`；`24387` connection refused。這表示 mGBA 0.10.5 CLI 的 `ports.qt.gdbPort` override 沒有改變 CLI GDB stub port。
4. 透過該 PID 所有的 `2345` 執行一次 `core/gba/capture_runtime.py`，但首個 `qSupported:multiprocess+` 在 client retry 後 timeout：`TimeoutError: mGBA did not answer 'qSupported:multiprocess+'`。沒有 runtime summary、VRAM/OAM/palette 或畫面可讀性證據產出。
5. 以 Ctrl-C 停止本次 PID；事後 `24387` 與 `2345` 均為 connection refused。

因此 palette、writer destination、實際 VRAM/OAM layout 與 glyph 畫面可讀性仍是
`blocked`，不能把 static POC 升格成 runtime QA。這次收據也不影響已確認的
font base／cell／table mapping；只保留 `RUNTIME-004` 作為 live evidence 邊界。

## confirmed／provisional／unknown

- **confirmed（static）**：manifest 的固定輸入 hash、27-slot allocation boundary、既有 mapping 不覆蓋、2 筆等長 target、兩個 PSI3 resource 原 span 內的 deterministic LZ77 重建、font／record／stream byte-level round-trip，以及 fail-closed rejection tests。
- **provisional（static POC）**：`的`／`你` 的 12×12 Unifont downsample 與 `ec48`／`ec49` code-unit assignment；它們只是測試 glyph，沒有翻譯審核、實機／runtime 畫面驗證或發布意圖。
- **unknown／blocked**：palette 值與色序、writer 寫入的實際 VRAM/OAM layout、runtime glyph 可讀性、未知 VM／排版語意、pointer／resource relocation、ROM header checksum／BPS builder，以及下一批可翻譯的術語與上下文。

下一個最小安全缺口是取得不干擾其他 session 的可重現 runtime renderer 證據，或以等價的本機 static writer／VRAM destination 證據完成分層；在此之前只維持 bounded manifest／POC，不開始大批 zh-TW 翻譯。
