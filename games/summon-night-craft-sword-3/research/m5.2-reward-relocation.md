# M5.2 resource-24 relocation translation slice

## 邊界

M5.2 是 M5.1 static pointer relocation POC 之後的第一個實際 resource-24
capacity-expansion slice。它只加入一筆 `ai_draft`、不開始批量翻譯，也不把 static
結果升格為 runtime 或可發布 patch。日文 source 仍只從 ignored
`research/summon-night-craft-sword-3-decoded.jsonl` 讀取；本文件與 tracked ledger
不保存完整原文。

## Ledger 分界與 target contract

再以 core 的 `restore_translations.rb` → ignored `work/` → `strip_translations.rb`
生成 `translations/m5.2-reward-relocation.jsonl`。`validate_ledger.py` 以固定
source-table hash、stable ID 與 core restore→strip JSON-value round-trip 驗證；tracked
ledger 沒有 `source`／`source_text` 欄位。

## Resource relocation 與重抽取

M2.5→M4.1→M4.2→M4.3 先以 ignored working copies 累積重建，再套用本批字型與
resource-24 record。原 directory entry 在 file `0x17190c4`：

- old payload `0x17231fc`、relative units `0xa20`、span `87` units／`1392` bytes
- new payload `0x1fbb1fc`、relative units `0x8a220`、span `0x60` units／`1536` bytes
- destination 是零填充、table-relative 16-byte aligned，掃描到的 aligned pointer refs 為 `0`
- 原 compressed size `1392`；新 compressed size `1396`，仍小於新 span `1536`
- new compressed bytes SHA-256：`01bc61826895c2a2e8928cde406eabadd1d88813f4197e1c829a68de7ab58a27`

builder 更新 directory pointer/span、在目的區寫入 compressed payload 加 zero fill，
再 decode resource 24 確認 decoded bytes 與 record region 一致。全部 13 個 resource
共 361 筆 re-extract 為 target `5`／untouched `356`；M5.2 generic re-extract 另外
保留三筆先前批次的 adjacent untouched record，resource-24 local proof 保留
`b3cj:t2:024:0x0046` 與 `b3cj:t2:024:0x0088`。local adjacent glyph `0x048` 的
cell／render hash 也與 clean ROM byte-identical。

## BPS 與 byte-level boundary

實際 build 產物只在 ignored `work/`：

- target ROM SHA-256：`da3b83b5470f278f455672021e2ae87452bc92d93fdbf1126c0e994dde757cb1`
- target ROM CRC32：`c81e7eb5`
- BPS size：`4814` bytes；SHA-256：`89fef3ad75b8ef60031378a62ae5488651e5a106adbba2442586e2a5769afc06`
- BPS apply 後 ROM SHA-256 與 target 完全相同
- cumulative changed bytes：`4357`；所有差異均落在既有 cumulative font/resource 範圍、directory entry 或 relocation destination

可重跑 build 會額外檢查 target code units、source record hash、resource span、
destination guard、pointer redirect、5 筆 target／356 筆 untouched，以及 existing
glyph `93c1/ec65/8140/8f64/8be0` mapping／cell 不變。M5.2 專用測試為 `2/2`。

## 尚未證實

本切片仍是 static-only：runtime QA 為 `pending`，沒有自然或受控 consumer hit、
font cache、writer→VRAM、palette、tilemap／OAM 或實際畫面可讀性證據；五筆 target
仍是 `ai_draft`，未完成人工翻譯／術語／版面審核。resource relocation 目前只由
本機 single-resource static guard 證實，不能推論所有 resource／alias 或可發布
patch 的完整 policy。下一個最小缺口是先保留這五筆的人工 review contract，再在
runtime transport 真正解鎖時對 target 與 adjacent data 做 live QA；不要擴大成全語料
批次或宣稱翻譯完成。
