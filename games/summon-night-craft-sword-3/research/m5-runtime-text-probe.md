1. A background launcher returned PID `99779` but exited before producing a
   listener or log output. No GDB packet was sent; this is a launcher lifetime
   negative.
2. A foreground fresh process reached the GDB greeting. The first probe
   progressed through readiness, breakpoints, and controlled-input phases but
   aborted in the probe's final memory summarizer when a non-hex `OK` response
   reached the old core-client read helper. No runtime claim was made from that
   incomplete report.
3. A fresh process with client host `127.0.0.1` failed at `connect()` with
   `OSError: [Errno 49] Can't assign requested address`; `qSupported` was not
   sent. This reproduces the prior controlled-connection negative.
4. A fresh process using the known successful host spelling `localhost`
   completed one GDB connection:

   - `qSupported`:
     `swbreak+;hwbreak+;qXfer:features:read+;qXfer:memory-map:read+;QStartNoAckMode+`
   - initial stop: `S02`
   - breakpoints set at local B3CJ `sub_0800D084`, `sub_080036F8`,
     `sub_08002CB4`, and `sub_0800B730`
   - ten bounded `S02` interrupt snapshots; no requested text breakpoint hit
   - controlled active-low KEYINPUT writes all returned `OK`: release `0x03ff`,
     A `0x03fe`, START `0x03f7`, and A+START `0x03f6`

The input route is explicitly **controlled** and is not natural reachability.
The ten stops were generated by the probe's interrupt timing, not by a text
consumer or writer breakpoint. No scratch argument hijack was used, and no
raw RAM/VRAM/OAM/palette dump or image was retained.

## Gate result

Transport is confirmed for one clean 2348 listener and one qSupported exchange,
but the controlled memory-injection path is not usable and text
consumer/writer coverage remains unknown. Changed glyph slots
`0x847/0x848/0x849`, adjacent `0x846`, live font cache, live VRAM,
tilemap/OAM state, and screen readability remain unverified. The static v3
writer/tile-data/OAM evidence is not promoted to runtime evidence. The next
runtime attempt must use a materially different argument/reachability path;
repeating the same IWRAM write or bind method is out of scope. Until a text
hit or an equivalent complete static release proof exists, the eight ledgers
remain `ai_draft`.
