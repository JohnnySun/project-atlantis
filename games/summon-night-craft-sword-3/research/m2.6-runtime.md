# B3CJ M2.6 第一筆翻譯 runtime renderer QA

本切片只驗證 M2.5 的唯一 target
`b3cj:t2:024:0x0064`（zh-TW `這次的獎品是…`）是否能在 patched ROM 中由
renderer 實際走到 cache／VRAM／畫面；ledger 維持 `ai_draft`，不擴大第二筆翻譯。
原文仍只存在 ignored source table，這份研究記錄不保存日文 source、raw RAM／VRAM、
screen dump、BPS 或完整 mGBA log。

## 前置 artifact guard

`tools/runtime_m2_6.py` 先核對 M2.5 ignored artifacts：

| artifact | receipt |
| --- | --- |
| clean base | B3CJ、32 MiB、CRC32 `12afae5d`、SHA-256 `39bc4cf448106aa4b8cdde235632ffb57432c4b1919c8843510b70b3787fad2d` |
| target ROM | CRC32 `74f884c4`、SHA-256 `da9c99426bf80c18729256a694ce6e499eab6d036fe26887908b8cb44cdf5b16` |
| BPS | 1543 bytes、SHA-256 `42618b4afffed33600f3f8f73b3e3f6bea3f7aa9ba8c74e5016121f9f7ec6e5b` |
| applied ROM | 與 target ROM byte-identical |

同一 guard 也驗證 M2.5 summary：target `1`、untouched `360`、全部 361 筆重抽取、
adjacent record proof，以及 runtime 狀態仍為 `pending`。M1.5 extractor 對 clean
ROM 的 source recovery confidence 仍是 `confirmed`（13 resources／361 records／
record 與 PSI3 stream round-trip）；本批譯文與 Unicode／字型 render confidence
維持 `ai_draft`／static provisional，沒有 runtime confirmation。

## Fresh launcher／listener attempts

其他 session 的 mGBA process 仍在使用各自 ROM／port；本輪只使用自有 PID，沒有附加、
停止或重用其他 process。高位 port `25126` 在 `lsof -nP -iTCP:25126 -sTCP:LISTEN`
檢查時沒有 listener；本環境的 raw socket bind/connect 會回報 `PermissionError`，
因此不把 sandbox 的 socket permission 當成 port 可用性的陽性證據。每個 launcher 都
重新啟動一次，沒有在同一 process 上重連。

| attempt | launcher／ROM ownership | process／listener | qSupported／判定 |
| --- | --- | --- | --- |
| 1 | PID `50537`；`/opt/homebrew/bin/mgba -C gdb.port=25126 -C skipBios=1 -g games/summon-night-craft-sword-3/work/m2.5-prize-ui-built.gba` | GUI launch 回報 `nice(5) failed: operation not permitted`，PID 很快退出，`/private/tmp/b3cj-m26-attempt1.log` 為 0 bytes；`25126` 無 listener | 沒有建立 connection，`qSupported` 未送出；自有 PID 已停止 |
| 2 | PID `50654`；`/private/tmp/atlantis-mgba-headless-build2/mgba-headless -C gdb.port=25126 -C skipBios=1 -g games/summon-night-craft-sword-3/work/m2.5-prize-ui-built.gba` | process log 首行為 `Debugger: Couldn't open socket`，PID 很快退出；`25126` 事後無 listener | `tools/runtime_m2_6.py`／core client 單次 readiness 在 connect 前回報 `PermissionError [Errno 1] Operation not permitted`；`qSupported` 未送出；自有 PID 已停止 |

兩輪都沒有 runtime breakpoint／watchpoint、natural navigation、controlled
argument hijack、font cache、writer destination、palette、VRAM／tilemap／OAM 或
screen hash。這是 transport-only negative，不是 ROM、BPS 或翻譯內容失敗；兩輪的
ignored JSON diagnostic 只保存 hashes、attempt／PID／port、error metadata 與 static
proof，沒有保存 raw GDB／RAM／VRAM。

重跑 hash guard／單次 readiness（輸出必須在 ignored `work/`）：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 games/summon-night-craft-sword-3/tools/runtime_m2_6.py \
  games/summon-night-craft-sword-3/roms/base/B3CJ-jp-from-zip.gba \
  games/summon-night-craft-sword-3/work/m2.5-prize-ui-built.gba \
  --bps games/summon-night-craft-sword-3/work/m2.5-prize-ui.bps \
  --bps-applied games/summon-night-craft-sword-3/work/m2.5-prize-ui-applied.gba \
  --summary games/summon-night-craft-sword-3/work/m2.5-prize-ui-summary.json \
  --plan games/summon-night-craft-sword-3/research/m2.5-batch-plan.json \
  --port 25126 --attempt 2 \
  --output games/summon-night-craft-sword-3/work/m2.6-runtime-attempt2.json
```

如果未來 listener 真正可用，`--capture` 只會在同一個 GDB client connection 上呼叫
共用 `core/gba/capture_runtime.py`；可再指定已審核的 writer breakpoint／watchpoint
與 ignored `--dump-dir`。沒有 `qSupported` readiness 時，工具不會產生任何 runtime
coverage 結論。

`b3cj:t2:024:0x0046`／`b3cj:t2:024:0x0078` byte-identical。

## 覆蓋與下一個最小缺口

- **confirmed**：base／target／BPS hash；target ID；三個 target code unit 的
  fallback→mapped／slot result；target static cell/render hashes；adjacent glyph
  `0x846` base／target equality；M2.5 record re-extraction 與 BPS apply。
- **provisional**：Unicode identity 與 static glyph appearance；`ai_draft` 譯文的
  語意、字寬與畫面排版尚未人工／runtime review。
- **blocked／unknown**：qSupported、自然 consumer reachability、controlled call
  coverage、font cache、writer→VRAM destination、palette、tilemap、OAM、screen hash
  與 live glyph readability。

下一次只接受新的可執行環境或 `/private/tmp` compile-time GDB-port mGBA build；先以
同一 hash-guarded diagnostic 完成 qSupported，再在一條 connection 內加入既有
renderer／writer breakpoint、必要時一次明確標記的 controlled argument hijack，最後
用 core renderer 比對 changed target 與 adjacent untouched。runtime gate 解鎖前不
建立第二筆 translation ledger，不改 `ai_draft` 或宣稱可發布。
