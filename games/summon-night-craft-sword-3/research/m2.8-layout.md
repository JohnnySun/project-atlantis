# M2.8：靜態 pointer／record／layout contract audit

本切片只收斂固定 B3CJ 日版 ROM 的靜態資料表與 record contract。報告不保存
日文原文、解壓 raw stream 或 ROM；完整 source table 與 audit JSON 仍在 ignored
`research/*-decoded.jsonl`／`work/`。

## 可重跑命令

```sh
PYTHONDONTWRITEBYTECODE=1 python3 \
  games/summon-night-craft-sword-3/tools/audit_layout.py \
  games/summon-night-craft-sword-3/roms/base/B3CJ-jp-from-zip.gba \
  --output games/summon-night-craft-sword-3/work/m2.8-layout-audit.json
PYTHONDONTWRITEBYTECODE=1 python3 \
  games/summon-night-craft-sword-3/tools/test_audit_layout.py
```

工具先驗證 ROM identity：`B3CJ`、32 MiB、CRC32 `12afae5d`、SHA-256
`39bc4cf448106aa4b8cdde235632ffb57432c4b1919c8843510b70b3787fad2d`。本次
audit summary 的 `audit_version` 是 `m2.8-static-layout-v1`，record-contract
aggregate SHA-256 為
`9aebe71ca654f735b41c913c08b79875f04b9b164a9c024373389b53dd70191e`。

## 已確認的 static contract

- 13 個含文字 record 的 resource ID 為 `9, 10, 11, 12, 14, 15, 16, 17,
  18, 19, 22, 24, 25`，共 361 筆 record；每筆 source Shift-JIS re-encode
  均 byte-identical（`361/361`）。
- type-2 table 的 pointer unit 是 16 bytes。13 筆 entry 形成 11 個不同的
  payload pointer group；resource `9`、`10` 是指向 resource `11` payload
  `0x172137c`（relative `0x838`）的 zero-span alias。其餘 positive span
  owner 為 `11, 12, 14, 15, 16, 17, 18, 19, 22, 24, 25`；所有 positive
  intervals 不重疊，且每個 compressed size 不超過自身 span。這只證明 table
  的 alias／容量關係，不等同於已完成 compressed container rebuild。
- 每筆 bounded text record 都觀察到一個 inline `0x0308` segment，以
  `0x0000` 結束。最大 payload 是 36 bytes／18 個 strict Shift-JIS code
  units；raw payload re-encode 為 byte-identical。
- 後續 command corpus 計數為 `0x0001:3`、`0x0002:90`、`0x0003:130`、
  `0x0006:9`、`0x0308:328`、`0x0309:58`、`0x030a:51`，另有 30 個
  opaque following-control occurrences。這些數字是結構計數，不是對未知
  opcode 的語意命名。

## 明確保留的未知項目

本切片沒有證實任何 line break、page、wait 或 glyph-width opcode；
`known_line_break_or_page_opcodes` 仍為空，opaque controls 原樣保留。record
修改契約因此仍限定為相同 byte length；zero padding、變長 record、pointer
relocation、LZ77／PSI3 container rebuild 與 ROM-level insertion 仍 blocked。
靜態 parser 也不能證明 palette、VRAM／OAM layout 或自然畫面可讀性；這些仍由
M2.7／`RUNTIME-007` 的 transport-only gate 分開限制。

## 驗證邊界

`tools/test_audit_layout.py` 另外驗證 compressed span overrun 會拒絕，以及
Shift-JIS code-unit count 必須 lossless。這個切片提供可重抽取的 pointer／record
contract，沒有擴大翻譯批次，也沒有把完整 ROM 回插或 runtime QA 宣稱為完成。
