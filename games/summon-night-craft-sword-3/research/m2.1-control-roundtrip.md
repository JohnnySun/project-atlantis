# B3CJ M2.1 控制碼保真與 round-trip 收據

固定輸入是 B3CJ `CRC32=12afae5d`、csm3 commit `7e388ac861bbac289b1f86dc5b8fa46d47b1a1a2` 與 M1.5 的 type-2／LZ77／`PSI3` extractor。本切片只證明解壓後的 PSI3 stream 與 record 層；不重建 LZ77、resource pointer、ROM 或字型。

## VM dispatch 與已命名形狀

csm3 的 `sub_080127E4` 以 command halfword 的 high byte 選 dispatch group，再由 low byte 索引 function table。對本作 0x0308 record 周邊，本輪只把有 csm3 callsite 且 parser 能驗證寬度的形狀命名如下：

| opcode | handler／證據 | 已確認的參數形狀 | 保守標籤 |
| --- | --- | --- | --- |
| `0x0308` | group-3 index 8 → `0x0800D085`（Thumb；csm3 `sub_0800D084`） | 後接記憶體原始 byte order 的 Shift-JIS bytes，至下一個 `u16 0x0000`；payload 長度可變 | text record |
| `0x0309` | group-3 index 9 → csm3 `sub_0800D36C`；函式讀 `gKeyHeld`／`gKeyNewPress`，沒有 script cursor read | 無 immediate stream parameter | input/state handler；不把它過度命名為已證實的「換行」或「分頁」 |
| `0x030A` | group-3 index 10 → csm3 `sub_0800D5D0` | 兩個 `sub_08012578` expression，各自以 `0x0000` 結束；之後是 stateful UI code | two-expression state handler；choice/page 語意仍 opaque |
| `0x0001` | group-0 index 1 → csm3 `sub_080128BC` | `u16, u16, expression_until_0` | store-like command |
| `0x0002` | group-0 index 2 → csm3 `sub_080131DC` | `u16 target, expression_until_0`；expression false 時跳到 aligned target | conditional branch |
| `0x0003` | group-0 index 3 → csm3 `sub_08013220` | 一個 aligned `u16` stream offset | unconditional jump |
| `0x0006` | group-0 index 6 → csm3 `sub_08012A94` | 一個 `expression_until_0`，其結果用作 resource／stack state | resource/state load；不猜 UI 語意 |

`sub_08012578` 的 expression callsite 另外證實：`0x0000` 是 expression terminator；`0x0001/2/3` 各帶一個 u16 operand；`0x0080/81` 是 unary operation；`0x0082..0x0091` 是兩個 stack value 的 arithmetic/comparison/bitwise/logical operation。parser 只把這些有 assembly case 的 opcode 命名，其餘 expression word 留在 `opaque_ops`。

未能由本輪固定 callsite 安全命名、但在 bounded post-record window 出現的 word，保留為 opaque token：`0x0302`（11 次）、`0x0304`（3 次）、`0x0316`（3 次）、`0x047e`（13 次）。它們不是被刪除或當作無參數處理；JSONL 只記錄 word、邊界與 hash。

## Corpus 交叉結果

對 13 個含 record 的 resource IDs `9,10,11,12,14,15,16,17,18,19,22,24,25`：

- 362 個 halfword-aligned `0x0308` candidates 中，361 個 strict Shift-JIS record 通過；1 個保持 rejected/opaque：resource 14、decompressed offset `0x02f4`、payload length 10、raw SHA-256 `ec528e655879ad9f9107c4bff868fe1f9725ecfd07763717d2ebac4a7ae11b69`。
- 361 筆 record 終止資料均為 `0x0000`；本輪沒有把任何 opcode 猜成換行或分頁。
- record 後第一個 command 的 bounded corpus count：`0x0308` 171、`0x0003` 103、`0x0309` 45、`0x030A` 39、`0x0002` 3。
- 每筆最多向後解析 8 個已知 command；窗口內結構化出 `0x0308` 328、`0x0003` 130、`0x0002` 90、`0x0309` 58、`0x030A` 51、`0x0006` 9、`0x0001` 3。遇到未知 word 即停止該窗口並保留 opaque boundary。
- 已命名 expression op 的 bounded-window count 為 `0x0001` 204、`0x0002` 90、`0x008B` 84、`0x0087` 5、`0x008A` 1；未在窗口中證實的 expression opcode 不被宣稱已出現於文字上下文。

每筆輸出的 stable `string_id` 與 M1.5 相同；新增的 `control_structure`、`following_controls`、`record_sha256` 與 `length_contract` 不改變 ID 或 pointer provenance。完整日文 `source_text` 與控制資料只存在 ignored JSONL。

## No-op encoder／round-trip

重跑命令：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 games/summon-night-craft-sword-3/tools/extract_static.py \
  games/summon-night-craft-sword-3/roms/base/B3CJ-jp-from-zip.gba \
  --output games/summon-night-craft-sword-3/research/summon-night-craft-sword-3-decoded.jsonl \
  --verify-roundtrip
```

## 每筆 payload 的長度契約

361 筆 record 都輸出同一個保守分類：

| 修改情境 | 判定 | 理由 |
| --- | --- | --- |
| payload 保持相同 byte length | `in_place_record_stream_confirmed` | `sub_0800D084` 只取得 inline pointer；後續 command／已證實 jump target 不會因相同長度而位移。此判定只到解壓 stream 層。 |
| 縮短後以 zero padding | `blocked_zero_is_record_terminator` | `0x0000` 是 text terminator；提前放 zero 會讓 handler 結束並把舊尾端誤當後續 stream，不能宣稱安全。非零空白 padding 的字寬／排版仍未證實。 |
| payload 變長 | `resource_rebuild_required` | record 是 command stream 內嵌資料；`sub_080131DC`／`sub_08013220` 使用 stream offset，變長會要求後續 command 與 jump target relocation，並需重新建 resource／LZ77。 |

下一個最小可翻譯批次的門檻是：選一個 resource 內的 1–2 筆 record，翻譯後 Shift-JIS byte length 必須與原值完全相同；保留 `0x0308`／`0x0000`、不改 following opaque/control token，通過 source hash、control structure、record/stream round-trip 與 ledger restore/strip。尚未找到字型／glyph identity 或可逆 resource builder 前，不開始實際翻譯。
