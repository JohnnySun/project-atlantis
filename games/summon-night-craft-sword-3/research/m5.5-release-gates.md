## Static writer → VRAM／palette hardware-copy receipt

`tools/audit_static_render_destination.py` 以 clean B3CJ identity、十三個本機 function
range hash 與十六個 literal pool guard fail closed。重跑命令：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 \
  games/summon-night-craft-sword-3/tools/audit_static_render_destination.py \
  games/summon-night-craft-sword-3/roms/base/B3CJ-jp-from-zip.gba \
  --output games/summon-night-craft-sword-3/work/m2.9-static-render-audit.json
```

ignored report SHA-256 是
`e38a2e8a5bc7d7ee10c41321132d01b42bef03c8f3d817be6afbe0fbfa5598ec`。

本地 ROM 與固定 csm3 commit `7e388ac861bbac289b1f86dc5b8fa46d47b1a1a2`
交叉成立的 static chain 是：

1. `sub_080036F8` 經 `sub_0800348C` lookup 呼叫 `sub_08002CB4`；writer 的
   `r1` 是 glyph output buffer，per-glyph stride／output span 為 `0x80`。
2. `sub_0800B730` 將該 output buffer、text-window field
   `gUnk_030056C0 + 0x194` 與 `glyph_count << 7` 交給 `sub_08006BA4`。
3. `sub_08006BA4` 將 source／destination／length 寫入
   `gUnk_03002DC0` descriptor queue；`DmaCopyMapAndPltt` 將 descriptor 寫入
   GBA DMA register `0x040000D4`。
4. `sub_0800D81C` 對本作 text window index 0 將該 destination field 初始化為
   `0x06010000`，再進入 `sub_0800B730`。因此本輪可確認的是 writer → queued DMA
   → VRAM character/tile-data region 的 static destination chain，不是 live hit。
5. `sub_080036C4` 從 ROM palette source table `0x08B6D610` 取值，經
   `sub_0800F224` 寫入 `gUnk_03005960` palette shadow formula
   `base + variant*0x0c + palette_index*0x20`，使用 indices `0x0e`／`0x0f`。
6. csm3 的 `sub_08001C00` main-loop callsite（本機 function hash guard）呼叫
   `sub_08010CD4`；該函式從 `gUnk_03005960 + 0x400 = 0x03005D60`，以
   `0x400` bytes 排入同一 `sub_08006BA4` DMA queue，目的為 `0x05000000`。
   因此 hardware palette destination 已有 confirmed-static evidence，但仍沒有
   live palette readback 或畫面色彩證據。
7. 本機 `sub_08001BC0` 呼叫 local `sub_080092CC` OAM transfer equivalent；
   function／literal guards 證實 `0x030038B0` → `0x07000000`、`0x400` bytes、
   DMA control `0x84000100`。這是 OAM buffer copy 的 static evidence，不是文字
   glyph/OAM 使用或畫面結果。
8. 本機 `sub_08009654` 與固定 csm3 `copy.c` formula 證實 text tile-data address
   `(((var->unk2 & 0x3ff) + var3->unk2) * 0x20) + 0x06010000`，stride `0x20`
   bytes（4bpp）、mask `0x3ff`、table root `0x030040C0`；不把它升格為 tilemap
   placement。

尚未由這條 bounded chain 證實 tilemap destination、live OAM values/layout、live font
cache、自然 reachability、VRAM bytes、screen hash 或 glyph readability。OAM transfer
與 text tile address 只作 static proof；tilemap／runtime 仍 unknown/false，hardware
palette 仍只作 destination proof，沒有把 static chain 升格為 runtime QA 或可發布 patch。

## Static text-object to OAM supplement

為了把「OAM copy 存在」與「文字 renderer 會建立 OAM metadata」分開，
`tools/audit_static_text_oam.py` 先重跑上述 audit，再以本機 B3CJ 的兩個額外
function hash 與五個 literal guard 驗證：

1. `sub_0800D81C → sub_0800B730` 是既有 text-window entry；`sub_0800B730`
   在 `sub_080036F8 → sub_08002CB4` 之後，按 glyph count 建立每字元 `0x28`-byte
   object descriptor。
2. main loop 的 `sub_08001C00 → sub_0800901C` 取用
   `gUnk_03003CC0`／`gUnk_030037B0`，將每個 object 的三個 OAM attribute
   halfword pack 到 `gOamBuffer=0x030038B0`。
3. 既有 `sub_08001BC0 → sub_080092CC` guard 再把該 buffer 接到
   `0x07000000`／`0x400`-byte hardware OAM DMA。

這個 supplement 讓 text-object→OAM buffer 的 static control-flow 有獨立收據，
但不把它升格為 live OAM、畫面或 glyph 可讀性證據；tilemap destination 仍
unknown。完整 hash／重跑命令見 [`research/m5-static-text-oam.md`](m5-static-text-oam.md)。

## Semantic multi-resource container rebuild

`tools/rebuild_container.py` 已對固定 13 個含 record resource、11 個 unique payload
groups 做 semantic no-op rebuild：每個 PSI3 token（含 opaque span）先 byte-identical
重發，再以 deterministic GBA LZ77 encoder 壓回原 pointer span，尾端 zero-fill。完整
收據見 [`research/m5-container-rebuild.md`](m5-container-rebuild.md)。

- 361/361 records 的 raw／record identity 與 `32092` stream bytes 保持一致；source
  Shift-JIS re-encode `361/361`，opaque `203`、rejected marker `1`。
- type-2 directory byte-identical；8191 changed bytes 全在既有 payload spans；rebuilt
  ROM SHA-256 `badb5838efafc3eb585c271208281bf44ce120ab46ec1ad573b4ddd55d185793`、CRC32
  `5344e805`，header checksum 未變。
- BPS `8615` bytes、SHA-256
  `326217ae194287d394fda8ef0296e095dff378d0c034238a48cae9c848080034`，套用後與
  rebuilt ROM byte-identical。

這只關閉 semantic LZ77／PSI3 container no-op 層；既有翻譯仍只對 resource 24 做
變長／relocation static rebuild，不能把本收據稱為全遊戲翻譯回插或發布 patch。

## 目前 gate 與下一個最小缺口

| gate | 狀態 | 證據邊界 |
| --- | --- | --- |
| 八筆 target static consistency | confirmed static / `ai_draft` | review metadata、glyph／layout／BPS／re-extract 已重跑；語意與專有名詞仍未人工定稿 |
| writer → DMA → `0x06010000` | confirmed static | function/literal hash 與 callsite chain；沒有 live memory |
| palette | confirmed static hardware destination | source table、shadow writer、main-loop copy caller、`0x05000000` destination 與 `0x400`-byte queue descriptor；沒有 live readback |
| semantic multi-resource LZ77／PSI3 rebuild | confirmed static | 13 resources／11 payload groups、361 records、directory unchanged、capacity guards、BPS apply byte-identical；不等於 translated multi-resource release encoder |
| text tile-data address | confirmed static | `sub_08009654` local hash/literals + csm3 formula；不等於 tilemap placement |
| OAM transfer path | confirmed static text-object chain | `sub_0800D81C` → `sub_0800B730` per-glyph descriptor → `sub_0800901C` → `gOamBuffer=0x030038B0`，再由 `sub_08001BC0` → `sub_080092CC` 複製至 `0x07000000`／`0x400` bytes；live values/layout 未讀 |
| tilemap | unknown | 本輪沒有 tilemap destination callsite，維持 fail-closed |
| mGBA/GDB runtime | partial live / text path pending | clean 2347 route 已有 qSupported、`S02`、palette DMA live call 與 controlled KEYINPUT writes；clean 2348 另有一次 listener／qSupported receipt，但 IWRAM `M` 回 `E06`、後續 probe 回 `Errno 49`；text consumer／writer／glyph VRAM／screen 仍未命中 |
| 可發布 patch | blocked | 仍缺人工翻譯／術語／字型審核、runtime 或等價完整畫面證據、全遊戲 coverage 與 release policy |

下一個有意義的工作只能關閉上述 gate（人工 review、允許 localhost 的 runtime、
更完整的 static tilemap/OAM callsite、或完整 container/release encoder）；
不再新增相同標頭或通用短句。
