# M5.3 repeated resource-24 prize header

## 邊界與來源分界

M5.3 是 M5.2 relocation batch 上的第二個 resource-24 record。選擇第二筆與
M2.5 完全相同的短標頭，讓本切片只驗證同一 relocated resource 的多筆 record
重建，不新增 glyph、專有名詞或 runtime 假設。target 維持 `ai_draft`，不是完整
翻譯或可發布 patch。

固定輸入仍是 clean B3CJ ROM SHA-256
`39bc4cf448106aa4b8cdde235632ffb57432c4b1919c8843510b70b3787fad2d`、source table
SHA-256 `a050790267679a35b1300f8ed3056271b6c481124790e9249484ce9d1d7966e3` 與
Unifont source SHA-256 `2ae5311c8e123e9e85f5331cd012aa99757071df23243f1487fdbf8f3acd86be`。
source adapter 與 working copy 只在 ignored `work/`；tracked ledger 由 core
`restore → work → strip` 產生，不含 `source`／`source_text`。

## Relocated resource proof

builder 會從 clean ROM 重新累積 M2.5→M4.1→M4.2→M4.3→M5.2，再修改本批
record；不把已存在的 ignored M5.2 ROM 當成唯一輸入。resource 24 directory
entry `0x17190c4` 保持 M5.2 的 relocated pointer：payload `0x1fbb1fc`、relative
units `0x8a220`、span `0x60`／`1536` bytes。M5.2 compressed size／SHA-256 是
`1396`／`01bc61826895c2a2e8928cde406eabadd1d88813f4197e1c829a68de7ab58a27`；
M5.3 新 compressed size／SHA-256 是 `1397`／
`c5dda0c3f24e6cdef2b559a4b676892737c56161d10bbb26c10d44945dceabd4`，仍通過
`1397 <= 1536` capacity guard。

所有 361 筆 record 重新抽取為 target `6`／untouched `355`。五筆先前 target
相對 M5.2 均 byte-identical；本批 adjacent records `b3cj:t2:024:0x00b4`、
`b3cj:t2:024:0x01f0` 與 clean byte-identical，adjacent glyph `0x048` 的 cell／
render hash 也保持不變。累積 changed bytes 為 `4355`，沒有超出既有 cumulative
font／relocation span。

## 尚未證實

本切片仍沒有自然或受控 runtime consumer hit、font cache、writer→VRAM、palette、
tilemap／OAM 或畫面可讀性證據；六筆 target 都仍是 `ai_draft`。它只證實本作
resource-24 在已知 zero-filled destination 的多筆 record static rebuild 與 BPS
一致性，不能推論其他 resource／alias、全遊戲排版、人工術語審核或可發布 patch。
