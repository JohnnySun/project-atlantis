## ledger 邊界

本作 extractor 的 ignored source key 是 `source_text`，而共用 ledger restore
契約要求本機 source adapter 使用 `text`；因此 `build_m2_5_batch.py prepare`
只在 ignored `work/` 產生一筆 bootstrap ledger 與一筆 source adapter，沒有改動
extractor 或把原文放進 tracked 檔案。可重跑流程是：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 games/summon-night-craft-sword-3/tools/build_m2_5_batch.py prepare \
  --source-jsonl games/summon-night-craft-sword-3/research/summon-night-craft-sword-3-decoded.jsonl \
  --plan games/summon-night-craft-sword-3/research/m2.5-batch-plan.json \
  --ledger-output games/summon-night-craft-sword-3/work/m2.5-seed-ledger.jsonl \
  --source-adapter-output games/summon-night-craft-sword-3/work/m2.5-source-adapter.jsonl
ruby core/ledger/restore_translations.rb \
  games/summon-night-craft-sword-3/work/m2.5-seed-ledger.jsonl \
  games/summon-night-craft-sword-3/work/m2.5-source-adapter.jsonl \
  games/summon-night-craft-sword-3/work/m2.5-prize-ui-working.jsonl
```

working file 與完整原文都留在 ignored `work/`。target UTF-8 hash 是
`ce6e829d970a7d1d4a0330637244dca64b0412b61ea88c4bdaa1687df6c0e2b0`。

## glyph／record／resource contract

目標 payload 維持 14 bytes、7 個 cell、1 line／7-cell static width。既有 mapped
Shift-JIS units 直接保留；新字只使用本批 plan 的三個 opaque extension units：

| code unit | Unicode identity | slot | static cell SHA-256 |
| --- | --- | --- | --- |
| `ec64` | `U+9019` | `0x847` | `fe98ddfeb980e6c596f05e497eb601bcc3759cb8eb7b7de11b0022a023710d6f` |
| `ec65` | `U+734E` | `0x848` | `b9304937fcc059ca6aad35452d6ad6ee1dc7459f5d01af674c459af061d50ae9` |
| `ec66` | `U+662F` | `0x849` | `fc1169558c952fa4bd2e917c02d2008a0b7325f00db368895ea7a1099df2d17f` |

`0x847..0x849` 都在 M2.2 allowed empty range；每個 extension unit 都先驗證為
非 strict Shift-JIS、clean ROM table value `0x0000`、物理 cell 全零，並拒絕
M2.3 的 `ec48/ec49` 假資料。任何既有 mapping、out-of-resource target、slot
重複、source／ROM／font hash、target unit、控制碼或長度不符都 fail closed。

`build_m2_5_batch.py` 重用 M2.3 的 deterministic LZ77 compressor 與 B3CJ static
font／record checks。resource 24 的 original compressed size／span 是 `1379/1392`；
本批重建為 `1392/1392`，剛好填滿原 span，因此沒有 expansion headroom，也沒有
修改 pointer table、resource directory 或 ROM header。

post-build raw re-extract 收到：

- total `361` records verified；target `1`、untouched `360`。
- target record／resource 24 stream byte-verified；其他 resource decoded bytes
  未變。
- adjacent untouched `b3cj:t2:024:0x0046`、`b3cj:t2:024:0x0078` 均保持
  byte-identical。
- changed bytes `1397`，差異只落在三個 font table/cell allocation 與 resource
  24 原 span；沒有 raw dump 或圖片進 Git。

target static ROM SHA-256 是
`da9c99426bf80c18729256a694ce6e499eab6d036fe26887908b8cb44cdf5b16`，target CRC32
是 `74f884c4`。core BPS 工具產生 `1543` bytes、BPS SHA-256

ROM 後 SHA-256 仍為 target hash，byte-for-byte 一致。

這是 static build／BPS POC，不是可發布 patch：M2.4 的 runtime launcher／GDB
handshake 仍 pending，尚無自然畫面 reachability、palette、VRAM／tilemap／OAM、
live glyph 可讀性或 runtime translation QA。此批仍是 `ai_draft`，下一步需做
翻譯自我複核／程序化字寬與 glyph QA，並在 runtime 解鎖後驗證該畫面；不能把
static target re-extract 或 BPS apply 升格成畫面通過。
