# M5.1：static type-2 pointer relocation POC

M2.5 已把 resource 24 的原 span 用滿，後續同一 resource 的翻譯不能靠放寬
原地 span。M5.1 先不改文字，對 clean B3CJ 的 resource 24 做一個可重跑的
directory redirect POC，確認回插器可以在安全的 free-space contract 上工作。

## 目的地與 fail-closed guard

- type-2 table：file `0x1718ffc`，resource 24 directory entry：`0x17190c4`
- clean resource 24 payload：`0x17231fc`，compressed `1379` bytes，span `87`
  units／`1392` bytes
- relocation destination：`0x1fbb1fc`，relative pointer units `0x8a220`，span
  `87` units／`1392` bytes
- destination 與 table base 的相對位址符合 16-byte pointer unit；整個目的區是
  ROM 內明確 zero-filled region，aligned ROM pointer references 為 `0`
- destination 不與已解析 type-2 table／resource spans 重疊；工具拒絕非零、未對齊、
  越界、重疊或被 pointer 指向的區域

## 重抽取證據

`tools/relocate_resource_poc.py` 只更新 resource 24 的 relative pointer/span，
將原 compressed bytes 複製到目的區並補零；舊 payload 不被清除。重導後重新跑
遊戲專用 extractor：`361 → 361` stable records，record identity digest
`fc8ac5a8754d0e804b2bbfe06d7a73ccbcb530c1b75eccc821359030fc7bcfca`，所有
`raw_sha256`／`record_sha256` 均 byte-identical；decoded stream 的 record
aggregate 前後都是
`154704fa319346491005c471b8ccb6ef4740463935b77eb541791736122d1937`。

POC relocated ROM SHA-256 是
`12375dbe202cbda942addfcbe8670e6e06d36e85f10569b39d1cc79b737b34bd`，只存在
ignored `work/`。這項證據只確認 directory redirect、LZ77 decode 與 static
re-extraction；尚未證實多 resource relocation、alias semantics、ROM checksum／
完整 patch policy、runtime reachability 或可發布 patch。
