# B3CJ M2.7 mGBA／GDB transport QA

本切片只處理 M2.5 唯一 target
`b3cj:t2:024:0x0064` 的 mGBA／GDB transport。沒有新增第二筆翻譯，也沒有把
M2.6 的 static glyph proof 升格成 live renderer 證據。target ledger 仍是
`zh-TW`／`ai_draft`；自然或受控 consumer hit、cache、VRAM、palette、tilemap、OAM
與畫面可讀性都只有在本輪 transport gate 解鎖後才可記錄。

## 固定 target artifact guard

`tools/runtime_m2_7.py` 重用 `tools/runtime_m2_6.py` 的 fail-closed guard，因此每次
probe 先核對以下 ignored artifact；ROM、BPS、完整日文 source、raw memory 與畫面輸出
均不在 Git：

| artifact | receipt |
| --- | --- |
| clean base | B3CJ、32 MiB、CRC32 `12afae5d`、SHA-256 `39bc4cf448106aa4b8cdde235632ffb57432c4b1919c8843510b70b3787fad2d` |
| M2.5 target | CRC32 `74f884c4`、SHA-256 `da9c99426bf80c18729256a694ce6e499eab6d036fe26887908b8cb44cdf5b16` |
| BPS | 1543 bytes、SHA-256 `42618b4afffed33600f3f8f73b3e3f6bea3f7aa9ba8c74e5016121f9f7ec6e5b` |
| applied target | 與 target ROM byte-identical |
| source／record proof | 361 records、target `1`、untouched `360`、M2.5 re-extract／BPS proof 通過 |

static guard 也重驗 target `ec64/ec65/ec66`→`0x847/0x848/0x849` 與 adjacent
untouched `0x846` 的 static cell/render equality。這些是本輪 runtime 的前置條件，
不是 live VRAM 或畫面結果。

## Fresh process／listener retry

每一輪都以 target ROM、不同 binary、不同高位 port 啟動 foreground mGBA；先用
`lsof -nP -iTCP:<port> -sTCP:LISTEN` 確認 port 沒有 listener，啟動後再次檢查，
再停止本輪自己的 process。沒有附加、重用或停止其他 session。PTY wrapper 只回傳
執行 session handle，沒有暴露 child OS PID；因此 report 的 `process_pid` 保持
`null`，不虛構 PID。launcher 絕對路徑、target ROM、port、listener 結果與錯誤均留在
ignored `work/m2.7-runtime-attempt*.json`。

| attempt | binary／launcher | port | listener | launcher result | cleanup |
| --- | --- | ---: | --- | --- | --- |
| 1 | `/private/tmp/atlantis-mgba-headless-build2/mgba-headless -C gdb.port=25273 -C skipBios=1 -g <target>` | `25273` | 啟動前後均無 | `Debugger: Couldn't open socket` | 只停止本輪 foreground process；事後 `lsof` 仍為空 |
| 2 | `/private/tmp/mgba-smt2-sdl-build/sdl/mgba -l 0 -C gdb.port=26371 -C skipBios=1 -g <target>` | `26371` | 啟動前後均無 | `Debugger: Couldn't open socket`；沒有可用 GDB listener | 只停止本輪 foreground process；事後 `lsof` 仍為空 |

兩輪都使用了使用者要求的 `-C gdb.port=<high-port>`，且第二輪改用另一個既有
mGBA binary，沒有再嘗試 `ports.qt.gdbPort` 或 port shim。`Debugger: Couldn't open
socket` 是 launcher／工具層收據，不是 ROM 或翻譯資料錯誤。

## Readiness-first single connection

每個已釋放 port 都只做一次獨立 probe；`runtime_m2_7.py` 透過共用
`core/gba/gdbstub_client.py` 使用 `0.08s` packet delay、ACK、一次 timeout retry，
並在任何 capture 前要求 `qSupported:multiprocess+`、`?`。本輪兩份 report 均為：

| attempt | report | connect | qSupported | error | consumer／VRAM |
| --- | --- | --- | --- | --- | --- |
| 1 | `work/m2.7-runtime-attempt1.json` | `false` | `null`／未送出 | `PermissionError [Errno 1] Operation not permitted` | 未嘗試 |
| 2 | `work/m2.7-runtime-attempt2.json` | `false` | `null`／未送出 | `PermissionError [Errno 1] Operation not permitted` | 未嘗試 |

這裡有兩個可重現的負面層次：mGBA 本身沒有在指定 port 建立 listener；在目前
執行環境直接用 localhost GDB client 也在 `connect()` 前被 socket policy 以
`PermissionError` 拒絕。因此不能把 `qSupported`、breakpoint、watchpoint、自然
navigation、controlled argument hijack 或任何 live memory 結果寫成已發生。

重跑（只會產生 ignored JSON）可用：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 games/summon-night-craft-sword-3/tools/runtime_m2_7.py \
  games/summon-night-craft-sword-3/roms/base/B3CJ-jp-from-zip.gba \
  games/summon-night-craft-sword-3/work/m2.5-prize-ui-built.gba \
  --bps games/summon-night-craft-sword-3/work/m2.5-prize-ui.bps \
  --bps-applied games/summon-night-craft-sword-3/work/m2.5-prize-ui-applied.gba \
  --summary games/summon-night-craft-sword-3/work/m2.5-prize-ui-summary.json \
  --plan games/summon-night-craft-sword-3/research/m2.5-batch-plan.json \
  --port 25273 --attempt 1 --listener-status absent \
  --launcher '/private/tmp/atlantis-mgba-headless-build2/mgba-headless -C gdb.port=25273 -C skipBios=1 -g <target>' \
  --output games/summon-night-craft-sword-3/work/m2.7-runtime-attempt1.json
```

第二輪只替換 `--port 26371`、`--attempt 2`、launcher 與 output。`--capture` 不應在
沒有 `qSupported` 時使用；若未來 listener 成立，才可在同一條 connection 加入已知
writer breakpoint／watchpoint，再用 core renderer 檢查 `0x847/0x848/0x849` 與
`0x846`。

## 覆蓋與下一個最小缺口

- **confirmed**：M2.5 base／target／BPS hash guard；兩個高位 port 的 preflight／
  postflight 無 listener；兩種 binary 都明確回報 socket failure；兩份 single-connection
  probe 的 `connect=false`／`qSupported=null`／`PermissionError`；static changed
  `0x847/0x848/0x849` 與 adjacent `0x846` 前置 proof。
- **not covered**：natural consumer hit、controlled consumer hit、font cache、writer
  destination、VRAM／palette／tilemap／OAM、changed／adjacent live hashes 與畫面可讀性。
- **remaining risk**：目前沒有證據判斷 launcher binary 的 GDB-port config 失效、執行環境
  bind policy，或兩者同時存在；也沒有 child OS PID 收據。下一個可執行方案是只在允許
  localhost socket 的環境重跑，或先在 `/private/tmp` 以 compile-time port 建立並記錄
  其 mGBA binary，再用這個 hash-guarded probe；本切片不再連續重試同一 bind 方法。

M2.7 因 transport gate blocked 而未開始自然／受控 renderer QA，沒有新增翻譯，也沒有
 宣稱 target 可發布。
