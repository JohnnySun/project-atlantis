## Decision boundary

The sources split between a direct character conversion `重金礦` and the
expanded Chinese form `重金礦石`. Wikipedia and the Bahamut page provide no
competing item rendering, so there is no multiple-source Taiwan consensus to
adopt. Per the repository proper-noun policy, keep the existing ledger target
`特獎　重金礦` as a provisional spelling, leave glossary status
`blocked_external_lookup`, and require human terminology approval before any
status change. No new glyph, source text, or translation row is introduced.
