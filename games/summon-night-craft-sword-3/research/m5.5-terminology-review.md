# M5.5 terminology review: `重金礦`

This is a bounded source review for the existing target
`b3cj:t2:024:0x0078`. It does not add a ledger row or change any target text.

## Sources checked on 2026-08-16

- [Wikipedia zh-tw: 召喚夜響曲 鑄劍物語 ～起源之石～](https://zh.wikipedia.org/wiki/%E5%8F%AC%E5%96%9A%E5%A4%9C%E9%9F%BF%E6%9B%B2_%E9%91%84%E5%8A%8D%E7%89%A9%E8%AA%9E_%EF%BD%9E%E8%B5%B7%E6%BA%90%E4%B9%8B%E7%9F%B3%EF%BD%9E)
  confirms the game identity, GBA platform and Japanese title, but its page
  has no item list or rendering for this ore.
- [巴哈姆特／鐵之狂傲攻略串](https://www.gamez.com.tw/thread-269282-1-1.html)
  was checked as the Taiwan-community source. It is a matching game攻略串,
  but its indexed text has no `重金`／`礦`／`礦石` occurrence, so it does not
  establish a community term for this item.
- [巴哈姆特精華區：礦物收集心得](https://forum.gamer.com.tw/G2.php?bsn=5499&sn=588)
  is a second Taiwan-community source and explicitly lists `《重金鉱》` in the
  mineral list. It preserves the Japanese source spelling rather than offering
  a competing translated form, but it independently confirms the item identity
  in the Taiwan fan context.
- [NG 新勢力系列討論](https://www.ng173.com/thread-290617)
  independently uses `重金鉱` in a material-combination note, providing a
  second community occurrence of the same source name.
- [Japanese item table at atwiki](https://w.atwiki.jp/wiki7_nakanohito/pages/6.html)
  lists the source item as `重金鉱` and gives its stats and acquisition
  context. This supports the source identity, not a Taiwan localization.
- [Chinese gameplay/cheat reference at PConline](https://pcedu.pconline.com.cn/1011/10114233.html)
  lists the corresponding material as simplified `重金矿石`. This is an
  independent Chinese rendering, but it is not a Taiwan source and does not
  establish a zh-TW majority.

## Decision boundary

The Japanese item name is independently repeated by the Taiwan-community
sources as `重金鉱`. Mainland Chinese references also show `重金矿` or
`重金矿石`, but those are not Taiwan-localization authorities and do not
outvote the direct traditional-character conversion. Per the repository
proper-noun policy, keep the existing ledger target `特獎　重金礦` as a
`provisional` spelling. This closes the external-lookup negative for this one
term, but it does not constitute human approval: the ledger remains
`zh-TW`/`ai_draft`, and no new glyph, source text, or translation row is
introduced.
