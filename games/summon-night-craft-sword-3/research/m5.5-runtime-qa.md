## Successful natural execution coverage

connected exactly once through `core/gba/gdbstub_client.py`, using host
`localhost`, timeout 8 seconds, packet delay `0.12` seconds and one retry
delay `0.35` seconds. The readiness response was:

```text
qSupported=swbreak+;hwbreak+;qXfer:features:read+;qXfer:memory-map:read+;QStartNoAckMode+
initial_stop=S02
```

The run collected 12 stops while the title/boot loop was executing. Every
palette-copy path reached the queue with the live register contract:

```text
r0 = 0x03005d60   source palette shadow
r1 = 0x05000000   hardware palette destination
r2 = 0x00000400   copy length

```

This is the first live confirmation of the static palette source/destination
chain. It does not prove that the translated prize record was displayed, and
it does not identify a changed glyph in VRAM. The probe did not save raw RAM,
VRAM, palette, screen or image data.

## Controlled attempt boundary

A second fresh target process was reserved for one controlled argument-hijack
attempt at the already verified `sub_080036F8` callsite. The listener was
present on 2347, but the single client connection failed before sending
`qSupported` with:

```text
OSError: [Errno 49] Can't assign requested address
```

Therefore no scratch EWRAM write, register overwrite, breakpoint hit or
controlled reachability claim was made. The process was stopped and the port
was verified free. This is a transport/startup negative for that attempt, not
a ROM or translation failure.
